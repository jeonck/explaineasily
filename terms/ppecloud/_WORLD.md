# PPE·클라우드 세계관: 공유 오피스 빌딩

## 무대
- 공유 오피스 빌딩 = 클라우드. 건물주 = IaaS 제공자(하드웨어). 완제품 사무실을 빌려주는 업체 = SaaS. 인테리어만 해주는 업체 = PaaS.
- 건물 관리사무소(오케스트레이션)가 어느 입주사(애플리케이션)에게 몇 칸을 배정할지 자동으로 정한다. 독채 사무실 = 가상머신(VM), 칸막이 책상 = 컨테이너. 시간제 회의실 = 서버리스.
- 배경: 낮 `sky()` = 평상시 운영, `bad-soft` = 자리 부족/장애 패널, `good-soft` = 확장·비교 패널.
- 긴장: 독채(VM)는 안전하지만 비싸고 느리게 뜨고, 칸막이(컨테이너)는 빠르고 싸지만 옆 칸과 더 가깝다(격리 수준의 트레이드오프).

## 등장인물 (헬퍼는 `terms/ppecloud/_world.py`)
| 인물 | 그림 | 실제 |
|---|---|---|
| 건물주 | `person(..., **LANDLORD)` 보라 | IaaS 제공자 |
| 관리사무소 | `person(..., **MANAGER)` 파란 모자 | 오케스트레이션(쿠버네티스) |
| 입주사 | `person(..., **TENANT)` 초록 | 애플리케이션 |
| 방문객 | `person(..., **VISITOR)` 주황 | 요청/트래픽 |

## 소품 = 개념
| 소품 | 헬퍼 | 실제 |
|---|---|---|
| 건물 | `building()` | 데이터센터 / 클라우드 |
| 사무실(shared=칸막이) | `office()` | VM(독채) / 컨테이너(칸막이) |
| 자동 좌석 배정 배지 | `deskbadge()` | 오케스트레이션(쿠버네티스) |
| 시간제 회의실 | `meetingroom()` | 서버리스 |
| 입주 안내판 | `floorplan()` | 안내판 / 구성도 |

## 깨지는 곳
- 칸막이(컨테이너)가 가볍다고 격리가 VM만큼 완벽한 건 아니다 — 옆 칸(이웃 컨테이너) 소음(자원 경합)이 넘어올 수 있다.
- 자동 배정(오케스트레이션)이 다 알아서 해줘도, 애초에 "몇 칸이 더 필요한지" 판단 기준은 사람이 정해야 한다.

## 다른 세계와의 다리
- `llmsec`(주방) 세계의 `toolsandbox` 와 비슷한 "격리" 개념이지만, 여긴 인프라 레벨(VM/컨테이너) 격리를 다룬다.

## 이미 쓴 비유 (order 순)
| slug | 제목 |
|---|---|
| cloudmodel | 뼈대만, 인테리어까지, 완제품 — 셋 중 골라 빌리기 |
| vmcontainer | 독채 사무실과 칸막이 책상 |
| govcloud | 검증된 건물에만, 등급에 맞춰 입주하기 |
| serverless | 쓸 때만 여는 시간제 회의실 |
| edgefog | 동네 가까운 지점과 그 사이 중간 허브 |
| svm | 두 그룹을 가장 넓게 갈라놓는 선 |
| dasnassan | 내 서랍, 공용 자료실, 전용 창고망 |
| aidc | GPU만을 위한 전용 별관 |
| storagetype | 벽돌, 폴더 트리, 태그 붙은 박스 |
| k8s | 자동 배정 배지의 그 유명한 제품 이름 |
| multicloud | 여러 건물에 동시에 입주하기 |
| scaleupout | 사무실을 키울까, 더 빌릴까 |
