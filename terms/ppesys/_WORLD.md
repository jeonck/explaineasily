# PPE·시스템SW 세계관: 자동차 정비공장

## 무대
- 정비공장 = 컴퓨터 시스템. 차량 = 프로세스/작업. 리프트(차 들어올리는 설비) = 공유 자원(CPU·메모리). 정비반장 = 운영체제 스케줄러.
- 공구함 = 캐시(자주 쓰는 공구를 가까이 둔다). 리프트 열쇠 = 세마포어/뮤텍스(한 번에 한 사람만 쓰게). 작업 순서판 = CPU 스케줄링 큐.
- 배경: 낮 `sky()` = 평상시 작업, `bad-soft` = 충돌·정체 패널(교착상태 등), `good-soft` = 해결·비교 패널.
- 긴장: 리프트(자원)는 한정돼 있는데 차(프로세스)는 계속 들어온다 — **누가 먼저 쓸지 순서를 정하는 것(스케줄링)**과 **서로 다른 리프트를 기다리며 꼼짝 못 하는 것(교착상태)**이 이 세계의 핵심 사건.

## 등장인물 (헬퍼는 `terms/ppesys/_world.py`)
| 인물 | 그림 | 실제 |
|---|---|---|
| 정비반장 | `person(..., **CHIEF)` 보라 | OS 스케줄러 |
| 정비사1/2 | `person(..., **MECH1/MECH2)` | 프로세스 / 스레드 |
| 손님 | `person(..., **CUSTOMER)` 주황 | 작업 요청 |

## 소품 = 개념
| 소품 | 헬퍼 | 실제 |
|---|---|---|
| 리프트 | `lift()` | 공유 자원 (CPU/메모리) |
| 차량 | `car()` | 프로세스 / 작업 |
| 공구함 | `toolbox()` | 캐시 메모리 |
| 리프트 열쇠 | `keyring()` | 세마포어 / 뮤텍스 |
| 작업 순서판 | `queueboard()` | CPU 스케줄링 큐 / 안내판 |

## 깨지는 곳
- 열쇠(뮤텍스)를 안 돌려주면 다음 차가 영원히 못 올라간다 — "안전장치"가 오히려 멈춤의 원인이 될 수 있다(교착상태).
- 공구함(캐시)을 늘린다고 항상 빨라지지 않는다 — 자주 안 쓰는 공구까지 담으면 오히려 뒤지는 시간이 늘어난다.

## 다른 세계와의 다리
- `sre`(놀이공원) 세계는 서비스 레벨의 가용성·확장을, 이 세계는 더 아래 레벨(OS·CPU·메모리·자료구조·알고리즘)을 다룬다.
