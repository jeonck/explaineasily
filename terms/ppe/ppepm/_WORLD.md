# PPE·IT관리 세계관: 콘서트 투어 기획사

## 무대
- 투어 기획사 = IT 프로젝트 조직. 투어 감독관(PMO/감리)이 전체를 점검하고, 기획자(PM)가 일정·예산을 짜고, 출연자(개발팀)가 공연(산출물)을 만들고, 후원사(발주처)가 비용을 대고, 관객(사용자)이 본다.
- 공연 티켓 = SLA(서비스 보장). 체크리스트 = WBS. 우산 = 위험관리(우천 대비). 출연 계약서 = 협상·계약.
- 배경: 낮 `sky()` = 평상시 준비, `bad-soft` = 위기 상황(우천·펑크) 패널, `good-soft` = 대응·성과 패널.
- 긴장: 공연은 미리 다 짜놓아도 날씨(위험)는 당일에야 안다 — **계획 vs 돌발 상황 대응**이 이 세계의 핵심 긴장.

## 등장인물 (헬퍼는 `terms/ppepm/_world.py`)
| 인물 | 그림 | 실제 |
|---|---|---|
| 투어 감독관 | `person(..., **DIRECTOR)` 보라 | PMO / 정보시스템 감리 |
| 기획자 | `person(..., **PLANNER)` 파란 모자 | 프로젝트 매니저(PM) |
| 출연자 | `person(..., **ARTIST)` 초록 | 개발팀 |
| 후원사 | `person(..., **SPONSOR)` 주황 | 발주처 |
| 관객 | `person(..., **FAN)` | 최종 사용자 |

## 소품 = 개념
| 소품 | 헬퍼 | 실제 |
|---|---|---|
| 티켓 | `ticket()` | SLA / 서비스 보장 |
| 체크리스트 | `checklist()` | WBS / 안내판 |
| 무대 | `stage()` | 산출물 / 서비스 |
| 우산 | `umbrella()` | 위험관리 |
| 계약서 | `contract()` | 협상·계약 |

## 깨지는 곳
- 완벽한 WBS(체크리스트)를 짜도 공연 당일 변수는 늘 남는다 — 계획은 "다 맞히는 것"이 아니라 "대응할 여지를 남기는 것".
- SLA(티켓 보장)를 너무 빡빡하게 잡으면 출연자(개발팀)가 작은 변수에도 위약금을 무는 구조가 된다.

## 다른 세계와의 다리
- `sre`(놀이공원) 세계의 `sla`/`slo` 는 기술적 신뢰성 관점, 이 세계는 계약·거버넌스 관점의 SLA/SLM을 다룬다 — 중복되면 링크.
