정보관리기술사·컴퓨터시스템응용기술사 시험 범위의 용어를 그림책으로 푼 자료의 목차다. 10개 분야, 213개 용어(한글·영문 각 213쪽)이며, 분야마다 비유 세계가 따로 있다.

이 파일은 `terms/ppe/<분야>/*.py` 의 `order`·제목에서 만든 것이다. 용어를 더하거나 제목을 바꾸면 다시 만든다.
