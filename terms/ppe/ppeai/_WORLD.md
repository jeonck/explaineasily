# PPE·AI이론 세계관: 농산물 품질검사장

## 무대
- 품질검사장 = AI 모델 전체. 컨베이어 벨트 = 데이터 파이프라인. 농작물 하나하나 = 데이터 포인트.
- 선별기 조작원(모델)이 작물을 보고 분류함(클래스)에 나눠 담고, 검수반장(평가지표)이 선별기의 성적을 채점하고, 훈련 교사(지도학습)가 미리 정답 예시로 선별기를 가르친다. 몰래 상한 작물을 섞는 사람도 있다(적대적 공격).
- 배경: 낮 `sky()` = 평상시 작업, `bad-soft` = 오분류·공격 패널, `good-soft` = 개선·검증 패널.
- 긴장: 선별기는 **기준을 사람처럼 "이해"하는 게 아니라 패턴으로 흉내**낸다 — 그래서 사람 눈엔 멀쩡해 보이는 작물에 아주 작은 흠집(미세 조작)만 내도 완전히 다르게 분류할 수 있다.

## 등장인물 (헬퍼는 `terms/ppeai/_world.py`)
| 인물 | 그림 | 실제 |
|---|---|---|
| 선별기 조작원 | `person(..., **OPERATOR)` 파란 모자 | 모델 / 알고리즘 |
| 검수반장 | `person(..., **INSPECTOR)` 초록 | 평가 지표 / 벤치마크 |
| 훈련 교사 | `person(..., **TEACHER)` 보라 | 지도학습 담당 |
| 몰래 섞는 사람 | `person(..., **CHEATER)` 어두운 색 | 적대적 공격자 |
| 농부 | `person(..., **FARMER)` 갈색 | 데이터 제공자 |

## 소품 = 개념
| 소품 | 헬퍼 | 실제 |
|---|---|---|
| 농작물 | `produce()` | 데이터 포인트 |
| 컨베이어 벨트 | `conveyor()` | 데이터 파이프라인 |
| 분류함 | `bin_()` | 분류(classification) / 군집 |
| 저울 | `scale_()` | 회귀분석 |
| 합격/불합격 도장 | `stamp2()` | 혼동행렬 / 성능 판정 |
| 등급표 | `gradeboard()` | 평가표 / 윤리기준 |

## 깨지는 곳
- 선별기의 "정답률 99%"가 항상 좋은 뜻은 아니다 — 상한 작물이 1%뿐이면, 전부 "멀쩡함"이라고 찍어도 99%가 나온다(혼동행렬이 필요한 이유).
- 선별기는 처음 보는 모양의 작물(분포 밖 데이터)엔 자신 있게 틀릴 수 있다.

## 다른 세계와의 다리
- `ai`(앵무새) 세계는 LLM/생성형 AI의 작동 방식을, 이 세계는 분류·회귀·군집 같은 전통적 머신러닝·통계 개념을 다룬다 — 겹치는 기초 용어(RAG 등)는 새로 쓰지 않고 링크한다.
- `llmsec`(주방) 세계의 `adversarialexample`/`datapoisoning` 과 같은 뿌리의 공격이지만, 여기서는 LLM이 아닌 일반 분류 모델 관점에서 다룬다.
