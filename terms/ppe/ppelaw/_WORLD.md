# PPE·법제도 세계관: 학교 규칙을 정하는 학생회

## 무대
- 학생회 = 표준화·법제도 기구. 학생회장이 규칙을 정하고, 각 분야 대표가 의견을 모으고, 선생님(감독기관)이 확인하고, 학생(조직/기업)이 따른다.
- 공용 준비물 라벨 = 라이선스 표시 의무. 의사봉 = 규칙 제정. 자동 검사기 = 레그테크(RegTech). 공지 게시판 = 공공데이터 공개.
- 배경: 낮 `sky()` = 평상시, `bad-soft` = 규칙 위반/분쟁 패널, `good-soft` = 합의·개선 패널.
- 긴장: 규칙은 모두에게 공평해야 하는데(망중립성 같은 원칙), 너무 세세하게 정하면 자유로운 활동(혁신)을 막는다 — **공정함 vs 자율성**.

## 등장인물 (헬퍼는 `terms/ppelaw/_world.py`)
| 인물 | 그림 | 실제 |
|---|---|---|
| 학생회장 | `person(..., **PRESIDENT)` 보라 | 표준·법 제정자 |
| 분야 대표 | `person(..., **REP)` 파란 모자 | 분야별 담당(산업·기술) |
| 학생 | `person(..., **STUDENT)` 주황 | 조직/기업 |
| 선생님 | `person(..., **TEACHER)` 초록 | 감독기관 |

## 소품 = 개념
| 소품 | 헬퍼 | 실제 |
|---|---|---|
| 규칙판 | `rulesboard()` | 법령/표준 안내판 |
| 준비물 라벨 | `suppliestag()` | 라이선스 / 표시 의무(SBOM 등) |
| 의사봉 | `gavel()` | 규칙 제정 |
| 자동 검사기 | `checkmachine()` | 레그테크(RegTech) |
| 공지 게시판 | `noticeboard()` | 공공데이터 공개 |

## 깨지는 곳
- 규칙을 만들었다고 저절로 지켜지진 않는다 — 확인하는 사람(감독기관)과 자동 검사기(레그테크)가 있어야 실효성이 생긴다.
- 전 세계가 같은 규칙(글로벌 표준)을 쓰길 바라지만, 나라마다 사정이 달라 합의가 느리다.

## 다른 세계와의 다리
- `security`(성) 세계의 `compliance` 와 `llmsec`(주방) 세계의 `aigovernance`·`sbom` 계열은 조직 내부 규칙에 가깝고, 이 세계는 산업 전체·국가 단위의 법·표준에 집중한다.
