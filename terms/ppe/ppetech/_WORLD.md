# PPE·신기술 세계관: 미래 과학관 전시장

## 무대
- 과학관 = 신기술 전시장. 전시 부스 하나하나 = 신기술 하나(디지털트윈 부스, 블록체인 부스, 메타버스 체험관, 드론 시연장 등).
- 안내원이 각 부스를 설명하고, 시연 담당자가 직접 보여주고, 관람객이 체험한다. 이 세계는 서로 다른 신기술을 억지로 하나의 기계장치로 엮지 않고, **"전시장을 걷는다"는 틀 하나**로 느슨하게 묶는다(용어마다 성격이 매우 달라서).
- 배경: 낮 `sky()` = 평상시 관람, `bad-soft` = 기술의 위험/한계 패널, `good-soft` = 활용 사례 패널.
- 긴장: 신기술은 멋있어 보이지만 전시장 밖(실제 현장)에서는 비용·보안·표준화 문제가 따로 있다 — **데모(시연) vs 실전(도입)**의 간극.

## 등장인물 (헬퍼는 `terms/ppetech/_world.py`)
| 인물 | 그림 | 실제 |
|---|---|---|
| 안내원 | `person(..., **GUIDE)` 보라 | 설명/해설 |
| 관람객 | `person(..., **VISITOR)` 주황 | 사용자/일반인 |
| 시연 담당자 | `person(..., **DEMO)` 파란 모자 | 기술 시연자 |

## 소품 = 개념
| 소품 | 헬퍼 | 실제 |
|---|---|---|
| 전시 부스 | `booth()` | 기술 분야 하나 |
| 입구 리본/현수막 | `ribbon()` | 전시 타이틀 |
| 시연 화면 | `screen()` | 디지털트윈 / 메타버스 등 시각화 |
| 전시 설명판 | `infoboard()` | 기술 설명/비교표 |

## 깨지는 곳
- 전시장에서 본 데모는 통제된 환경이다 — 실제 현장(공장·도로·가정)은 변수가 훨씬 많다(스마트팩토리, 자율주행 등의 실전 격차).
- 서로 다른 전시 부스(기술)들이 겉보기엔 따로지만, 실제로는 서로를 기반으로 삼는 경우가 많다(예: 디지털트윈은 엣지컴퓨팅·IoT 위에서 동작).

## 다른 세계와의 다리
- `llmsec`(주방) 세계의 공급망/투명성 개념이 블록체인 보안 등과 맞닿지만, 여긴 기술 자체의 개념 설명에 집중한다.
