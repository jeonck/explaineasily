In one breath

Adversarial attack = subtly perturbing an input so it looks the same to a person but the sorter classifies it completely differently.

An adversarial attack is an inference-time attack that adds a perturbation (noise, a pattern) too small for a human to notice, making an already-trained classifier misjudge exactly the way the attacker wants. White-box attacks, which need knowledge of the model's weights, make a more precise perturbation; black-box attacks, without that knowledge, work by repeated trial. The same principle applies beyond images — to audio, text, and tabular classifiers alike. Unlike data poisoning, which corrupts the training data itself, an adversarial attack targets a model that has already finished learning.

When grown-ups say it

Adversarial attack
A perturbation that looks the same but gets classified differently. Happens against a model that has already finished training.
Data poisoning
Spoiling the seed — the training data itself. A different attack timing — during training. → the kitchen world's data poisoning
Perturbation
A small change too faint to notice. A slight nudge to dots or edges.
White-box · black-box
Whether you know the sorter's inner rule, or only try by trial. Knowing the inner rule lets the perturbation be far more precise.
Misclassification
Dropping something into the wrong bin. The outcome an adversarial attack is built to cause.
Confusion matrix
The four-box table sorting pass/fail stamps. An adversarial attack quietly wrecks these numbers. → The Four-Box Stamp Ledger
Outlier
The one item that stands out from the rest. One defense is exactly this: spotting it. → The Produce That Stands Out from the Crowd
Image injection (LLM/vision angle)
The same-rooted attack in the world where a person reads a menu photo. The angle where an LLM reads a hidden command in a photo lives in the kitchen world. → The Picture Order That Fools the Eye
