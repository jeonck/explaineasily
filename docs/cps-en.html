What is a Cyber-Physical System (CPS)?

Cyber-Physical Systems, told as a story about a booth where a screen twin and a real mechanical arm move in lockstep.

Isn't that robot arm on screen just an animation?If it only moves on screen, isn't that just an animation?

It's no good if the screen and the real machine move independently.The screen bends the arm, but the real arm just sits there unmoved.

A CPS is a digital twin on screen and a real machine, locked together by sensors and signals.Change the screen and the machine moves — move the machine and the screen updates too.

Read the statea sensor reads the real machine
Mirror on screenmirrors it onto the twin
Calculate a commanddecides what happens next
Act in realitythe command moves the real machine

The signal makes a full circle and comes back to the start.This loop that keeps circling is called a feedback loop.

A late or hacked signal lets the twin and reality drift apart.The signal's speed and safety matter just as much as what's on screen.

In one breath

CPS = a closed-loop system that mirrors a sensor-read real state onto a screen (digital twin), then uses that judgment to move the real machine again.

A Cyber-Physical System links sensors, networks, and computing to physical machinery in real time, so that sensing, deciding, and controlling run as one continuous feedback loop. A digital twin is the virtual model that plays the 'screen' role in a CPS, and most real-world applications of new technology — smart factories, autonomous driving, smart farms — run on this same CPS structure.
