개인정보 보호강화기술(PET)이 뭐예요?

개인정보 보호강화기술(PET)을 손님을 지키는 여러 다른 도구가 담긴 도구상자 이야기로 풀어봤어요.

다 가리면 분석을 못 해요.안전하지만 쓸모가 없어요.

다 보여주면 위험해요.분석은 잘 되지만 손님이 위험해져요.

PET는 손님을 지키는 여러 다른 도구가 담긴 도구상자예요.한 가지 방법만 있는 게 아니라, 상황에 맞춰 고를 수 있어요.

차분 프라이버시결과에 살짝 흐림을 섞어요
동형암호자물쇠 채운 채로 계산해요
연합학습데이터는 각자 집에 두고요
합성데이터닮은 가짜 명부를 만들어요

네 기법은 쓰는 상황이 서로 달라요.빠르고 가벼운 것도 있고, 느리지만 안전한 것도 있어요.

완벽한 프라이버시와 완벽한 정확도는 같이 안 돼요.가명처리와 마찬가지로, 어디까지 가릴지는 늘 맞바꿈이에요.

한 줄로

PET(개인정보 보호강화기술) = 차분 프라이버시·동형암호·연합학습·합성데이터 같이, 데이터를 보호하면서도 쓸 수 있게 만드는 여러 도구.

PET는 개인정보를 가리거나 암호화한 상태에서도 분석·학습이 가능하도록 돕는 기술들을 통칭해요. 차분 프라이버시는 결과값에 통계적 잡음을 더해 한 개인의 존재 여부를 숨기고, 동형암호는 암호문 상태 그대로 연산해 복호화 없이 결과를 얻고, 연합학습은 원본 데이터를 모으지 않고 각 기기에서 학습한 모델만 모으고, 합성데이터는 실제 분포를 흉내 낸 가짜 데이터를 생성해요. 어떤 기법도 프라이버시와 정확도·효율을 동시에 완벽히 만족시키진 못해, 상황에 맞춰 조합해서 써요.

어른들은 이렇게 불러요

차분 프라이버시
Differential privacy
결과에 살짝 흐림 섞기. 통계적 잡음을 더해 한 사람 때문에 결과가 바뀌었는지 못 알아보게 해요.
동형암호
Homomorphic encryption
자물쇠 채운 채 계산. 열어 보지 않고도 답만 얻어요. → 열쇠 없이는 못 읽는 편지
연합학습
Federated learning
집집마다 따로 배우기. 데이터는 그 자리에 두고, 배운 결과만 모아요.
합성데이터
Synthetic data
닮은 가짜 명부. 진짜 손님 대신 비슷한 특성의 가짜 손님을 만들어 분석·테스트에 써요.
영지식증명
Zero-knowledge proof
내용 안 보여주고 증명하기. 비밀번호를 말하지 않고도 안다는 걸 증명하는 것 같은 기법이에요.
프라이버시-정확도 트레이드오프
Privacy-accuracy trade-off
시소. 더 가리면 더 안전하지만 덜 정확해져요.
가명처리
Pseudonymization
번호표로 바꿔 달기. PET보다 먼저 쓰는 기본 도구예요. → 번호표로 바꿔 달고, 진짜 이름은 다른 금고에
데이터 결합
Data linkage/combination
여러 성의 장부 합치기. 안전하게 합치려면 특별한 방에서만 해요. → 밖으로 못 들고 나가는 특별 열람실
