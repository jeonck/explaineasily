데이터 표준화가 뭐예요?

데이터 표준화를, 반마다 다르게 적던 출석부를 전교 공통 기준표 하나로 맞추는 학생회 이야기로 풀어봤어요.

반마다 출석부 적는 방식이 달라요.처음엔 각자 편한 대로 적었을 뿐이에요.

합치려니 숫자가 안 맞아요.형식이 다르면 숫자를 믿고 합칠 수 없어요.

데이터 표준화는 전교가 함께 쓰는 공통 용어·형식·코드표예요.같은 말, 같은 형식, 같은 코드를 쓰면 전교 숫자를 믿고 합칠 수 있어요.

표준 용어 정하기같은 뜻은 같은 이름으로
표준 형식·범위 정하기올 수 있는 값의 틀을 정해요
코드로 통일하기같은 값은 같은 코드로
이름 짓는 규칙 정하기코드·변수 이름도 규칙대로

표준화 전후를 비교하면 이렇게 돼요.숫자가 아니라 '약속'을 맞추는 일이에요.

표준도 계속 고쳐 나가야 해요.새 상황마다 기준표를 다시 다듬어야 해요.

한 줄로

데이터 표준화 = 여러 반(시스템)이 같은 용어·형식·코드를 쓰게 맞춰, 숫자를 믿고 합칠 수 있게 하는 일.

데이터 표준화는 여러 시스템이 같은 의미의 데이터를 같은 용어(표준용어)·같은 형식과 범위(표준도메인)·같은 코드값(코드표준)·같은 명명규칙으로 다루게 맞추는 작업이에요. 기관 간 데이터를 연계·통합할 때 표준이 없으면 같은 값도 다르게 해석되어 통계와 연계가 무너져요. 표준은 데이터 사전에 모아 공개하고, 새로운 상황이 생길 때마다 계속 보완해야 해요.

어른들은 이렇게 불러요

데이터표준화
Data Standardization
전교가 같은 말·형식·코드를 쓰게 맞추는 일. 숫자를 믿고 합칠 수 있게 해줘요.
표준용어
Standard Terminology
같은 뜻은 같은 이름으로 부르는 것. 반마다 다른 이름을 쓰면 헷갈려요.
표준도메인
Standard Domain
값이 올 수 있는 형식·범위를 정하는 것. 날짜 형식을 YYYY-MM-DD로 맞추는 것 같은 일이에요.
코드표준
Code Standard
같은 값은 같은 코드로 적는 것. 1=출석처럼 숫자 코드로 통일해요.
명명규칙
Naming Convention
이름을 짓는 공통 방식. 코드명·변수명도 이 규칙을 따라요.
데이터 사전
Data Dictionary
전교 기준표를 한 곳에 모아둔 목록. 누구나 찾아볼 수 있게 공개해요.
데이터 품질
Data Quality
표준을 지켜야 믿을 수 있는 숫자가 나와요. 소프트웨어의 '좋음' 기준과 닮았어요. → 좋은 준비물의 기준표
공공데이터 개방
Open Data
표준을 지킨 데이터라야 바깥에도 공개할 수 있어요. 다른 세계에도 비슷한 창고가 있어요. → 문을 열고 번호표를 달아 연결해두는 창고
