In one breath

Anti-drone is a set of technologies that detects, identifies, and disables an intruding drone — while managing the risk of false positives and jamming side effects.

An anti-drone system detects drones with radar, electro-optical/infrared (EO/IR) cameras, and RF sensors, identifies friend from intruder using flight patterns and signals, then disables the target via jamming, net capture, or direct takedown. Small, low-altitude, low-RCS (radar cross-section) drones are inherently hard to detect, and jamming can affect nearby communications and navigation equipment, so its use comes with legal and technical constraints.

When grown-ups say it

Anti-Drone
The set of technologies that finds and stops an intruding drone. Made up of three stages: detect, identify, disable.
RF Sensor
The sensor that catches a drone's control signal. A key tool in the detection stage.
Jamming
Cutting the signal between drone and controller. Can affect nearby communications too.
Low RCS
Being hard for radar to catch. Why small drones are hard to detect.
MEC
Computing nearby a base station for speed. A similar idea helps process detection data fast. → the MEC booth
Smart City
Using citywide data to keep things safe. A safety-service example, like early disaster warning. → the Smart City booth
False Positive
Mistaking an ordinary drone for an intruder. Easy to get if the identify stage is skipped.
Aviation Safety Regulation
The law that limits both drones and anti-drone use. Governs how far jamming may be used too.
