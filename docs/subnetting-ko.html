네트워크 서브네팅이 뭐예요?

서브네팅을, 큰 동네를 작은 우편번호 구역으로 나눠 각자 우체국을 두는 이야기로 풀어봤어요.

동네 전체가 우편번호 하나예요.집이 수천 채면 하나씩 다 들러야 해요.

구역을 안 나누면 전부 같이 번져요.혼잡도 장애도 동네 전체에 같이 번져요.

서브네팅 = 동네를 작은 우편번호 구역으로 나누는 거예요.구역마다 전용 우체국을 두니 찾기도 관리하기도 쉬워져요.

나누기큰 동네를 쪼개요
빨리 찾기구역만 알면 끝
자(마스크)로 자르기어디까지가 구역인지
전용 구역혼잡·장애를 가둬요

자(마스크)가 앞뒤를 나눠줘요.라우터는 앞자리만 보고 바로 그 구역으로 보내요.

너무 잘게 쪼개도, 너무 크게 둬도 손해예요.적당한 구역 크기를 고르는 게 중요해요.

한 줄로

서브네팅 = 하나의 큰 동네(네트워크)를, 각자 우체국을 둔 작은 우편번호 구역들로 나누는 일.

서브네팅은 하나의 IP 네트워크를 서브넷 마스크로 네트워크부와 호스트부를 나눠, 더 작은 여러 개의 서브넷으로 쪼개는 작업이에요. 이를 통해 주소 공간을 효율적으로 쓰고, 트래픽과 장애 영향 범위를 구역 단위로 가둘 수 있어요.

어른들은 이렇게 불러요

IP 주소
IP Address
동네와 집을 가리키는 번지수. 보낼 곳을 특정하는 숫자예요.
서브넷 마스크
Subnet Mask
앞뒤를 나눠주는 자. 네트워크부/호스트부 경계를 정해요.
CIDR
CIDR
자 눈금을 숫자 하나로 적는 법. 예: /24 처럼 표기해요.
네트워크부/호스트부
Network/Host Part
구역 번호 / 그 안의 집 번호. 주소를 둘로 쪼갠 구성이에요.
라우팅 테이블
Routing Table
어느 구역으로 보낼지 적힌 안내판. 라우터가 늘 보는 지도예요. → 집배원끼리 길을 찾아 전달하는 법
OSI 3계층(네트워크)
OSI Layer 3
구역과 길을 정하는 단계. 주소·구역 나누기가 이 계층 일이에요. → 7단계로 나뉜 배송 공정
DNS
DNS
번지수 대신 이름으로 찾게 해주는 주소록. 다른 세계(보안)에서 자세히 다뤄요. → 이름으로 찾는 주소록
L4 스위치
L4 Switch
구역 안에서 창구 번호까지 보는 분류 직원. 구역이 나뉜 뒤 안쪽에서 더 세밀히 나눠요. → 포트까지 보는 분류소 직원
