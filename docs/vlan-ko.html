VLAN이 뭐예요?

가상 LAN(Virtual LAN)을 색 리본으로 나눈 복도 이야기로 풀어봤어요.

복도가 하나면 다 섞여요.손님 노트북이 금고 방 문을 두드릴 수 있어요. 복도 파수꾼이 걱정하는 그 일이에요.

벽을 세우려면 복도를 새로 지어야 해요.복도 셋을 새로 짓는 건 비싸고 오래 걸려요.

VLAN은 색 리본으로 복도를 나눠요.벽 대신 리본이에요. 파란 리본은 파란 리본끼리만 이야기해요. 복도는 하나, 마을은 셋.

리본색마다 번호가 있어요
같은 색끼리소리쳐도 같은 색만 들어요
색을 넘으려면문지기를 지나요
한 통로에 여러 색건물 사이는 같이 지나요

색을 넘으려면 문지기를 지나야 해요.손님(초록)이 금고(빨강)로 가려면 문지기가 목록을 봐요. 건물 사이 통로 하나엔 리본 여러 색이 같이 지나가요 — 트렁크예요.

리본은 벽이 아니라 약속이에요.리본을 바꿔 달면 넘어갈 수 있어요. 그래서 구멍 문지기가 리본을 달아주고, 색 사이엔 진짜 문지기를 둬요.

한 줄로

VLAN = 복도 하나를 색 리본으로 여러 복도처럼 나누는 것. 같은 색끼리만 이야기하고, 색을 넘으려면 문지기를 지나요.

Virtual LAN, IEEE 802.1Q. 리본은 1부터 4094까지 번호가 붙은 태그예요. 리본을 더 잘게 나누면 마이크로 세그멘테이션 — 문마다 물어보는 성의 복도 판이에요.

Tag · VLAN ID
리본 색. 1부터 4094까지 번호. 리본은 사람이 아니라 구멍이 달아줘요.
브로드캐스트 도메인
Broadcast domain
소리가 들리는 범위. 소리치면 같은 색만 들어요.
액세스 포트
Access port
한 색만 다는 구멍. 꽂으면 그 색 리본을 달아줘요. → 복도 구멍마다 문지기
트렁크
Trunk
여러 색이 같이 지나는 통로. 건물 사이 통로 하나에 리본을 달고 다 같이 가요.
인터 VLAN 라우팅
Inter-VLAN routing
색 사이 문지기. 초록에서 빨강으로 가려면 여길 지나요. → 문이 많은 성벽
VLAN 호핑
VLAN hopping
리본 바꿔 달기. 리본이 약속인 걸 노린 도둑의 수법.
네이티브 VLAN
Native VLAN
리본 없는 사람 취급. 리본이 없으면 이 색으로 쳐요. 도둑이 자주 노려요.
마이크로 세그멘테이션
Micro-segmentation
리본을 더 잘게. 방 하나, 물건 하나 단위까지. → 문마다 물어보는 성
