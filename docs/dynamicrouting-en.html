In one breath

A dynamic routing protocol is a set of rules by which post offices (routers) trade news and update the delivery map (routing table) themselves — RIP, OSPF, and other IGPs.

RIP (Routing Information Protocol) is a distance-vector protocol that propagates hop counts only to neighbors — simple but slow. OSPF (Open Shortest Path First) is a link-state protocol that shares the whole topology map and computes shortest paths — fast and scalable. Both are IGPs (Interior Gateway Protocols) used inside one organization (autonomous system); between organizations, a separate EGP like BGP is used instead.

When grown-ups say it

Dynamic routing
Post offices trading news and redrawing the map themselves. Static routing, by contrast, is redrawn by hand.
RIP
Spreading only to neighbors, by rumor. Judges distance by counting hops.
OSPF
Sharing the whole map with everyone. Computes the shortest path from link state.
IGP
A category of routing rules used only inside one organization. RIP and OSPF both belong to this category.
Hop count
The number of post offices a parcel passes through. The yardstick RIP uses to judge a route.
Convergence
The time it takes for news to spread to every post office. During this time, the map isn't fully accurate yet.
IPv6
