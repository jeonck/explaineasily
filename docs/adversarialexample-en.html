In one breath

Adversarial example = a photo that looks the same to a human eye but is subtly perturbed so the chef reads it entirely differently.

An adversarial example is an input with a perturbation (noise, a pattern) so small a human can't notice it, crafted to make a model's recognition or classification fail in a chosen way. This applies to images as well as audio and text, and can be crafted with knowledge of the model's weights (white-box) or without it, through repeated trial (black-box). Unlike prompt injection, which hides an instruction, an adversarial example contains no hidden instruction at all — it simply breaks the model's perception itself.

Adversarial example
A photo that looks the same but is read differently by the chef. Not a hidden command — the seeing itself is wrong.
Image injection
Hiding a text command inside a picture. Covered on the page right before this one. → letters hidden in a menu photo

White-box · black-box
Whether you can see the recipe book, or only try by trial. Knowing the recipe book lets the perturbation be far more precise.
Classifier
The chef's eye, which looks at a photo and tags what it is. Fooling this eye is exactly what an adversarial example aims for.
Misclassification
Tagging something with the wrong label. The outcome an adversarial example is built to cause.
Guardrail
The taster who checks a note's words. Since the seeing itself is wrong — not the words — even this taster can't catch it. → What is a Guardrail?
