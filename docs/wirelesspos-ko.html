무선 측위가 뭐예요?

무선 측위(위치 기반 기술)를, 여러 신호탑에서 거리를 재어 지금 위치를 찾는 이야기로 풀어봤어요.

도심 건물 숲에서 집배원이 길을 잃어요.건물 숲에 둘러싸여 지금 위치를 알 수가 없어요.

위성 신호가 건물에 가려 약해져요.건물에 가려 신호가 안 닿거나 약해요.

여러 신호탑에서 거리를 재어 내 위치를 찾아요.원 세 개가 겹치는 한 점이 바로 지금 있는 자리예요.

위성(GPS)멀리서도 정확하지만 실내엔 약해요
기지국 신호신호 세기로 대략 위치를 가늠해요
와이파이/비콘실내에서 부족한 부분을 보완해요
삼변측량세 곳 이상 거리를 겹쳐 위치를 계산해요

측위에는 여러 신호가 쓰여요.위성은 야외에, 기지국은 대략, 와이파이는 실내 보완에 맞아요.

실내에선 오차가 커지고, 여러 방식을 섞어 써요.그래서 위성·기지국·와이파이를 섞어 쓰는 하이브리드 방식을 써요.

한 줄로

무선 측위는 여러 신호탑(위성·기지국·와이파이)에서 오는 신호로 거리를 재어 지금 위치를 찾아내는 기술이에요(삼변측량).

무선 측위는 GPS 같은 위성 신호의 도착 시간차로 거리를 계산하는 삼변측량이 기본이지만, 실내·도심에서는 신호가 약해지거나 반사돼 오차가 커져요. 이를 보완하려고 이동통신 기지국 신호 세기(RSSI)나 실내 와이파이/BLE 비콘 신호를 함께 쓰는 하이브리드 측위가 널리 쓰여요.

어른들은 이렇게 불러요

무선 측위
Wireless positioning
여러 신호탑 거리로 내 위치를 찾는 기술. 삼변측량이 기본 원리예요.
삼변측량
Trilateration
세 곳 이상 거리를 겹쳐 위치를 계산하는 것. 원이 겹치는 한 점이 위치예요.
GPS
GPS
가장 흔히 쓰는 위성 측위 신호. 실내·도심에선 약해질 수 있어요.
RSSI
RSSI
받은 신호의 세기. 가까운 기지국일수록 세게 받혀요.
BLE 비콘
BLE beacon
실내 위치를 보완하는 작은 신호 발신기. 위성이 안 닿는 실내에서 요긴해요.
5G 네트워크 슬라이싱
5G Network slicing
한 도로를 전용 차선으로 나누는 것. 측위 신호도 특정 슬라이스로 우선 처리될 수 있어요. → 도로를 차선으로 나누기
다중접속 제어
Multiple access control
여러 집배원이 한 길을 나눠 쓰는 규칙. 측위 신호도 결국 이 규칙으로 통로를 나눠 써요. → 하나의 통로를 안 부딪히고 나눠 쓰는 법
VPN
VPN
몰래 파는 안전한 터널. 위치 정보가 오갈 때도 이 터널로 보호되기도 해요. → 몰래 파는 안전한 터널
