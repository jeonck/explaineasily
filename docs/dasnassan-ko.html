DAS/NAS/SAN이 뭐예요?

DAS/NAS/SAN 스토리지를, 내 책상 서랍·건물 공용 자료실·건물 전용 창고망의 차이로 풀어봤어요.

각자 책상 서랍만으론 보관이 금방 한계예요.더 보관할 곳이 필요해요.

사무실마다 따로 보관하면 중복되고 나누기 힘들어요.나눠 쓸 방법이 필요해요.

DAS=내 서랍, NAS=공용 자료실, SAN=전용 창고망이에요.연결 방식과 나눠쓰는 범위가 셋 다 달라요.

DAS는 내 책상에 직접 꽂아요혼자만 쓸 수 있어요
NAS는 복도망으로 나눠 써요파일 단위로 여러 사무실이 써요
SAN은 전용망, 블록 단위예요더 빠르지만 비싸요
나눠쓸수록 관리도 복잡해져요비용도 같이 올라가요

연결 방식과 공유 범위로 세 가지가 갈려요.속도·비용·공유범위가 함께 움직여요.

작은 사무실엔 전용 창고망(SAN)이 오히려 과해요.규모에 맞는 걸 고르는 게 중요해요.

한 줄로

DAS = 내 책상에 직접 연결된 서랍(혼자 사용). NAS = 복도망으로 연결된 건물 공용 자료실(파일 단위 공유). SAN = 건물 전용 창고망(블록 단위, 빠르고 비쌈).

DAS(Direct Attached Storage)는 서버에 직접 연결되는 저장장치, NAS(Network Attached Storage)는 일반 네트워크로 연결해 파일 단위로 여러 서버가 공유하는 저장장치, SAN(Storage Area Network)은 전용 고속 네트워크로 연결해 블록 단위로 접근하는 저장 전용망이에요. 공유 범위와 속도·비용이 DAS < NAS < SAN 순으로 커져요.

어른들은 이렇게 불러요

DAS
DAS (Direct Attached Storage)
내 책상에 직접 연결된 서랍. 혼자만 쓸 수 있어요.
NAS
NAS (Network Attached Storage)
복도망으로 연결된 건물 공용 자료실. 파일 단위로 여러 사무실이 나눠 써요.
SAN
SAN (Storage Area Network)
건물 전용 고속 창고망. 블록 단위라 더 빠르지만 더 비싸요.
블록 스토리지
Block storage
벽돌처럼 조각난 저장 단위. 더 자세한 비교는 다른 페이지에서 다뤄요. → 블록·파일·오브젝트
파일 스토리지
File storage
폴더 트리처럼 정리된 저장 방식. NAS가 쓰는 방식이에요.
네트워크 대역폭
Network bandwidth
복도망이 한 번에 나를 수 있는 양. NAS·SAN 속도에 직접 영향을 줘요.
클라우드 스토리지
Cloud storage
건물 전체가 대신 보관해 주는 서비스. DAS/NAS/SAN 중 무엇이든 그 바탕이 될 수 있어요.
백업
Backup
자료실 사본을 따로 하나 더 두는 일. 공유 범위가 넓을수록 백업도 더 중요해져요.
