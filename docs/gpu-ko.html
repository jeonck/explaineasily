GPU/GPGPU가 뭐예요?

GPU와 GPGPU를, 똑같은 간단한 일을 한번에 나눠 하는 보조 정비팀 이야기로 풀어봤어요.

똑같은 타이어 점검이 산더미처럼 쌓여요.반장 혼자서는 하나씩밖에 못 봐요.

더 뛰어난 정비사 한 명을 데려와도 여전해요.결국 한 번에 한 대씩이에요.

GPU = 수백 명이 똑같은 간단한 일을 나눠 하는 보조 정비팀이에요.한 명 한 명은 단순하지만, 같이 움직이면 엄청 빨라요.

코어 수백~수천 개손이 그만큼 많다는 뜻이에요
SIMD모두에게 같은 동작을 동시에 시켜요
처리량 우선복잡한 한 가지보단 단순한 여럿
GPGPU원래 그림용 보조팀을 계산에도 써요

CPU와 GPU는 잘하는 일이 달라요.GPU는 단순한 걸 '많이 동시에' 잘해요.

복잡하고 갈라지는 일에는 안 맞아요.GPU는 CPU를 대신하지 않아요 — 서로 다른 일을 나눠 맡아요.

한 줄로

GPU = 똑같이 단순한 일을 수백~수천 개의 작은 손이 한번에 나눠 처리하는 보조 정비팀. GPGPU는 이 팀을 그림 작업 말고 일반 계산에도 쓰는 것.

GPU(Graphics Processing Unit)는 수많은 단순 코어로 동일 연산을 여러 데이터에 동시에 적용하는 SIMD(Single Instruction, Multiple Data) 구조예요. 원래 픽셀·정점 연산을 병렬 처리하려고 만들어졌지만, 행렬 연산이 많은 딥러닝 등 범용 계산에도 쓰이게 되면서 GPGPU(General-Purpose computing on GPU)라는 말이 생겼어요. CPU는 적은 수의 강력한 코어로 분기·순차 로직을 빠르게 처리하는 데, GPU는 많은 수의 약한 코어로 처리량(throughput)을 극대화하는 데 강해요.
