In one breath

SDN is a tower rerouting every road at once, in software; NFV is installing a function as software on generic hardware instead of a dedicated machine.

SDN (Software-Defined Networking) separates the control plane from the data plane, letting one central controller govern a network's paths and policy entirely in software. NFV (Network Functions Virtualization) turns the function of dedicated hardware middleboxes — routers, firewalls — into software (VNFs) running on generic servers. Used together, they make a network fast and flexible to reconfigure.

When grown-ups say it

SDN
A tower that reroutes roads in software. Separates control from the field.
NFV
Installing a function on a generic truck instead of a dedicated machine. Turns hardware into software.
Control plane
The layer where the tower makes decisions. Doesn't carry anything itself.
Data plane
The real post offices that actually carry the parcels. Simply executes what the tower decides.
Virtual Network Function
A software function installed on a generic truck. Even a firewall or sorter can run this way.
