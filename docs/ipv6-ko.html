IPv6가 뭐예요?

IPv6를, 동나버린 번지수 체계를 훨씬 길게 늘려 새로 만든 주소 이야기로 풀어봤어요.

번지수가 다 떨어졌어요.번지수 체계(IPv4)의 숫자가 다 쓰였어요.

한 번지수를 여러 집이 억지로 나눠 써요.새 집은 번지수를 못 받고, 임시방편도 한계가 있어요.

IPv6는 번지수 체계를 훨씬 길게 늘린 거예요.4덩이에서 8덩이로 늘려 사실상 무한한 새 주소를 만들었어요.

훨씬 긴 주소32비트에서 128비트로 늘었어요
거의 무한한 개수지구 모래알보다 많아요
자동 주소 할당스스로 주소를 만들어 받기도 해요
호환 작업 필요옛 체계와 당장은 안 섞여요

IPv4와 IPv6는 네 가지가 달라요.IPv6는 훨씬 길고 많고, NAT도 필요 없어요.

아직 완전히 바뀌진 않았어요.당분간은 두 체계를 함께 쓰는 과도기예요(듀얼스택).

한 줄로

IPv6는 번지수 체계를 32비트에서 128비트로 훨씬 길게 늘려, 사실상 무한에 가까운 새 주소를 만든 것이에요.

IPv6(Internet Protocol version 6)는 약 43억 개뿐인 IPv4 주소 고갈 문제를 해결하기 위해 주소 길이를 128비트로 늘린 차세대 인터넷 프로토콜이에요. NAT 없이도 기기마다 고유 주소를 줄 수 있고, 자동 주소 설정(SLAAC) 같은 기능도 갖췄어요. IPv4와 직접 호환되지 않아 듀얼스택·터널링 같은 과도기 기법을 함께 써요.
