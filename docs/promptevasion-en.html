In one breath

Prompt filter evasion = keeping the meaning the same while disguising only the shape of the words, so the note slips past the taster's eyes.

Prompt filter evasion uses encoding, misspellings, language switches, or syllable splitting to change the surface form of an input so it slips past a guardrail's pattern matching. Unlike jailbreaking, which makes the content itself more persuasive, evasion keeps the intended meaning the same and only changes its expression — so filters need to normalize input or layer multiple checks to catch it.

When grown-ups say it

Prompt filter evasion
A note that changes only its shape to pass the taster. The content stays the same — only the surface changes.
Guardrail
The taster who checks the note. See it in more depth in the AI world. → What is a Guardrail?
Pattern matching
The taster's way of only looking for a known shape. It compares shapes, not meaning.
Encoding bypass
A note rewritten like a code. base64 and unicode substitution are common methods.
Normalization
The taster converting different shapes back to the same letters. The basic countermeasure against evasion.
Jailbreak
A note that persuades by changing the content itself. A different method from disguising only the shape. → What is a Jailbreak?
Red team
People who deliberately disguise notes to test the taster. AI red teams hunt for this too. → the security world's red team
Hallucination
Confidently continuing even when unsure. Even given a disguised note, the chef answers just as confidently. → What is a Hallucination?
