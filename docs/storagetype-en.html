What are Block, File, and Object Storage?

Block, file, and object storage, told as the difference between raw bricks, a folder tree, and a warehouse of tagged boxes.

Every tenant wants to store things in a different shape.Bricks, folders, boxes — all different shapes.

With only one storage shape, somebody's stuff never fits.Neither bricks nor box tags work here.

Block=bricks, file=folder tree, object=tagged boxes.All three differ in how things get stored and retrieved.

Block = raw bricksthe rawest, and the fastest
File = a folder treemost familiar to people
Object = tagged boxesfound by querying tags via an API
Object storage piles up almost without limitthe warehouse just keeps growing

They differ on all four measures.Use cases split clearly — block for databases, file for shared docs, object for photos and backups.

Object storage is slow because the whole box has to be resent.Block storage lets you swap just one piece, quickly.

In one breath

Block is raw bricks (fast, unstructured). File is a folder tree (familiar to people). Object is tagged boxes (near-infinite scale, found by metadata).

Block storage is accessed in fixed-size chunks, suited to fast I/O like databases. File storage uses a directory/file hierarchy that's easy for people to navigate. Object storage keeps data as objects tagged with metadata and a unique ID, queried via an API, with near-unlimited horizontal scale — ideal for unstructured bulk data like photos, backups, and logs. But objects are inefficient to partially modify.

When grown-ups say it

Block storage
Storage carved into brick-like chunks. Fastest, but completely unstructured.
File storage
Storage organized like a folder tree. Most familiar for a person to navigate.
Object storage
A warehouse of boxes tagged with metadata. Found by querying tags via an API.
Metadata
The tag attached to the box. The key used to find an object.
DAS / NAS / SAN
A difference in connection method and sharing scope. A different axis — connection method, not data shape. → my drawer, the shared file room, the dedicated network
Horizontal scaling
Adding more warehouse space sideways, endlessly. This is how object storage scales almost without limit.
Backup
Keeping one more copy of the data elsewhere. A common use case for object storage.
Cloud service model
Bare shell / interior done / move-in ready. Whichever model you rent, you still pick one of these three. → pick one to rent
