What is Logistic Regression?

Logistic regression, told as a story about feeding the scale's number through an S-curve to get a pass probability.

It has to answer pass or fail — only one of the two.The scale gives a number, but the number by itself isn't the answer.

Using the raw score directly as a probability makes no sense.A probability has to stay between 0 and 1 — but a raw score doesn't respect that range.

It feeds the scale's number through an S-curve to get a pass probability.No matter how big or small the score, the result always lands between 0 and 1.

Score itcombining features into one score
Squash it with an Ssqueezing the score between 0 and 1
Pass the cutoff, call it PASS0.5 is the usual cutoff line
Draw the boundarythe line that splits pass from fail

Both use the scale — but they're answering a different question.One asks 'how much'; the other asks 'which side'.

It squashes with an S — but underneath, one straight line still does the dividing.For a more complicated boundary, you'd check performance with a confusion matrix and reach for a different method.

In one breath

Logistic regression = feeding the scale's score through an S-curve to get a pass probability between 0 and 1.

Logistic regression is a supervised classification method that passes a linear combination (weighted sum) of input features through a sigmoid function, turning the result into a probability between 0 and 1. If that probability clears a threshold (usually 0.5), it's classified as the positive class; otherwise, the negative class. Despite the word 'regression' in its name, it's actually used for classification — and because its decision boundary is fundamentally a straight line (a hyperplane), it struggles with data that needs a more complicated, curved boundary.

When grown-ups say it

Logistic regression
Feeding the scale's number through an S-curve to get a probability. Despite its name, it's used for classification.
Sigmoid function
The S-curve that squashes any number into 0 to 1. The core mechanism of logistic regression.
Linear regression
Predicting the raw scale number itself — a continuous value. The original owner of the scoring method logistic regression borrows.
Decision boundary
The line that splits pass from fail. In logistic regression, this boundary is always a straight line (or flat plane).
Threshold
The cutoff that turns a probability into pass or fail. Usually 0.5, but it can be moved depending on the situation.
Odds ratio
The ratio of the pass probability to the fail probability. The term used when interpreting a logistic regression coefficient.
Confusion matrix
The ledger that splits pass/fail calls into four boxes. Logistic regression's own performance is checked the same way. → The Four-Box Stamp Ledger
Clustering
Finding groups on its own, with no answer labels. A neighboring method that starts from the opposite assumption. → Grouping by Likeness, With No Name Tags
