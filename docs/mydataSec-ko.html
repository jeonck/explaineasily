마이데이터가 뭐예요?

마이데이터(MyData)를, 여러 가게에 흩어진 내 장부를 내가 직접 다른 가게로 보낼 수 있는 권리 이야기로 풀어봤어요.

손님 장부가 여러 가게에 흩어져 있어요.내 장부가 어느 가게에 뭐가 있는지, 나도 한눈에 못 봐요.

가게마다 장부는 자기 것이라고 해요.장부는 가게에 있지만, 적힌 내용은 전부 손님 이야기예요.

마이데이터는 내 장부를 내가 보낼 곳을 정하는 권리예요.내 동의가 있으면 가게끼리 바로 보내줘요. → CBPR이 나라 간 이전이라면, 마이데이터는 손님 본인의 이전 요청이에요.

내 것이라고 선언해요장부 내용은 손님의 것이에요
보낼 곳도 내가 정해요가게 A에서 가게 B로 직접
한곳에 모아 볼 수 있어요여러 가게 장부를 합쳐서 봐요
동의마다 새로 정해요언제든 다시 거둘 수 있어요

실제로는 이런 순서로 움직여요.동의 → 요청 전달 → (허가받은 사업자) → 전달 완료. 아무 가게나 마음대로 보내주는 게 아니에요.

편한 만큼, 지켜야 할 것도 늘어나요.허가받은 사업자만 다룰 수 있고, 전달 통로 보안이 특히 중요해요 → 개인정보 보호, 데이터 3법 개정

한 줄로

마이데이터 = 여러 가게에 흩어진 내 장부는 내 것이니, 내가 동의하면 가게끼리 직접 주고받을 수 있는 권리.

MyData, 본인 신용정보·개인정보 이동권. 개인이 자신에 관한 정보를 보유한 기관에 전송을 요구하면, 그 기관이 본인이나 본인이 지정한 다른 기관·마이데이터 사업자에게 표준화된 방식(API)으로 데이터를 전달하는 제도예요. 한국은 신용정보법 개정으로 금융 마이데이터가 먼저 시작됐고, 허가받은 마이데이터 사업자만 중계할 수 있어요.

어른들은 이렇게 불러요

마이데이터
MyData
내 장부는 내가 보낼 곳을 정하는 권리. 정보 주체 본인이 전송을 요구할 수 있는 권리예요.
전송요구권
Right to data portability
보유 기관에 전송을 요구하는 권리. 가게가 거절할 수 없는, 손님이 쥔 요구권이에요.
마이데이터 사업자
Licensed MyData operator
가게 사이를 중계하는 허가받은 심부름꾼. 허가받은 곳만 할 수 있어요.
표준 API
Standardized API
정해진 전달 통로. 가게마다 다른 방식이 아니라, 정해진 한 가지 통로로 전달돼요.
동의 철회
Withdrawing consent
보낸 걸 다시 거두는 것. 언제든 전송 동의를 거둘 수 있어요.
신용정보법
Credit Information Act
금융 마이데이터를 먼저 연 법. 데이터 3법 중 하나예요. → 데이터 3법 개정
개인정보 보호
Privacy
보낸 뒤에도 지켜야 하는 약속. 마이데이터는 동의 기반 전송이지 보호 의무를 없애진 않아요. → 손님 이름표는 손님 것
CBPR
CBPR
나라 사이의 비슷한 이전 규칙. 마이데이터는 손님 본인의 요청, CBPR은 나라 간 인증이에요. → CBPR
