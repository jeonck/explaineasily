전송계층의 역할이 뭐예요?

전송계층을, 동네까지 온 봉투를 정확한 창구로 넘기고 등기·일반우편을 고르는 단계 이야기로 풀어봤어요.

동네까지는 왔는데 어느 창구로 가야 할지 몰라요.동네 안에도 웹용, 메일용 창구가 따로 있어요.

확실함(등기)과 속도(일반우편) 중 하나를 골라야 해요.확실함과 속도, 둘 다 가질 순 없어요.

전송계층 = 창구 번호를 나누고 등기·일반우편을 고르는 단계예요.동네까지 온 봉투를 정확한 창구와 방식으로 넘겨줘요.

포트 구분창구 번호로 나눠요
신뢰도 선택등기냐 일반우편이냐
분할·재조립큰 짐을 조각내요
흐름 제어상대 속도에 맞춰요

전송계층은 이 네 가지 일을 해요.상대가 못 받으면 속도를 늦춰 넘치지 않게 해요.

전송계층이 길(라우팅) 자체를 정하진 않아요.가는 길 자체는 한 단계 아래(네트워크계층)에서 정해져요.

한 줄로

전송계층 = 동네(주소)까지 온 봉투를 창구 번호(포트)로 나누고, 등기(TCP)·일반우편(UDP) 중 방식을 고르는 단계.

전송계층(OSI 4계층)은 포트 번호로 같은 호스트 안의 여러 서비스를 구분하고, TCP(연결지향·신뢰성)나 UDP(비연결·속도) 중 하나로 데이터를 주고받으며, 필요하면 데이터를 세그먼트로 나누고 흐름·혼잡 제어로 수신 속도를 조절해요. 목적지(주소)를 정하는 네트워크계층과는 역할이 구분돼요.

어른들은 이렇게 불러요

포트 번호
Port Number
동네 안 몇 번 창구인지. 같은 주소 안 서비스를 구분해요.
TCP
TCP
확인받고 보내는 등기 봉투. 연결지향적이고 신뢰성이 높아요.
UDP
UDP
확인 없이 빠르게 보내는 일반 봉투. 비연결형이고 빠르지만 잃어버릴 수 있어요.
세그먼트
Segment
전송계층에서 조각난 데이터 단위. 패킷과 비슷하지만 이 계층만의 이름이에요.
흐름·혼잡 제어
Flow/Congestion Control
상대 속도에 맞춰 보내는 속도를 늦추는 것. 등기(TCP)가 느려지는 이유 중 하나예요.
L4 스위치
L4 Switch
포트까지 보고 창구를 나누는 분류 직원. 이 계층의 정보를 실제로 활용하는 장비예요. → 포트까지 보는 분류소 직원
네트워크계층(서브네팅)
Network Layer (Subnetting)
동네(주소)를 정하는 한 단계 아래. 전송계층은 이 계층 위에서 동작해요. → 동네를 작은 우편번호 구역으로 나누기
IPC(네트워크)
Network IPC
포트로 상대를 특정하는 전용 편지함. 전송계층의 포트 개념을 그대로 쓰는 예시예요. → 프로세스끼리 여는 전용 편지함
