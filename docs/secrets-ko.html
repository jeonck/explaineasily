시크릿 관리가 뭐예요?

시크릿 관리(Secrets Management)를 목수가 도면에 못 박아 둔 창고 열쇠를 잠긴 상자로 옮기는 이야기로 풀어봤어요.

목수가 편하려고 열쇠를 도면에 못으로 박아 뒀어요.목수는 창고 문을 열 때마다 열쇠를 가지러 가기 싫었어요. 그래서 도면에 열쇠를 박아 뒀어요. 편하긴 해요.

도면은 복사돼 마을로 나가요. 열쇠도 같이요.도면은 원래 여기저기 복사되는 거예요. 열쇠가 박힌 채로 복사되면, 마을 사람 모두가 창고 열쇠를 갖게 돼요.

시크릿 관리는 열쇠를 벽에 못 박아 두지 않는 거예요.열쇠는 잠긴 상자에 넣어요. 도면엔 '열쇠 상자 3번 칸'이라고만 적어요. 필요할 때 경비에게 잠깐 빌리고, 자주 바꿔요.

잠긴 상자에도면이 아니라 상자에
잠깐 빌리기쓰고 나면 돌려줘요
자주 바꾸기훔쳐도 금방 안 맞아요
도면엔 칸 번호만'3번 칸'이라고만 적어요

열쇠를 자주 바꾸면, 훔친 열쇠는 금방 쓸모없어져요.열쇠는 매달 새것으로 바꿔요. 목수는 잠깐 빌려 쓰고 돌려줘요. 그래서 지난달 열쇠를 훔친 도둑은 문을 못 열어요.

경비는 도면에 열쇠가 박혀 있는지 늘 검사해요.사람은 또 못을 박아요. 그래서 도면 검사가 열쇠 모양을 찾으면 종을 울려요. 벽돌 하나 쌓을 때마다, 자동으로요.

한 줄로

시크릿 관리 = 열쇠를 도면에 못 박지 않고 잠긴 상자에 두고, 필요할 때 잠깐 빌리고, 자주 바꾸고, 도면엔 칸 번호만 적는 일.

Secrets Management. 비밀번호, API 키, 토큰, 인증서 같은 시크릿을 코드에 하드코딩하지 않고 볼트에 보관해요. 코드는 이름으로 참조하고, 실행할 때 잠깐 받아 쓰고, 주기적으로 로테이션해요.

어른들은 이렇게 불러요

시크릿
Secret
창고 열쇠. 비밀번호, 입장권, 봉인 편지의 열쇠. 들키면 문이 열려요. → 열쇠 대신 입장권
하드코딩
Hardcoding
도면에 못 박기. 열쇠를 코드 안에 글자로 적어 두는 것. 편하지만 도면이 가는 곳마다 따라가요.
볼트
Vault
잠긴 열쇠 상자. 열쇠를 한곳에 모아 잠그고, 누가 언제 꺼냈는지 일지에 적어요. → 금고 속 마스터 열쇠
로테이션
Rotation
매달 새 열쇠. 정해진 때마다 열쇠를 바꿔요. 훔친 열쇠의 유통기한이 짧아져요.
환경 변수
Environment variable
일하러 갈 때 주머니에 넣어 주는 열쇠. 도면(코드)엔 없고, 일 시작할 때만 잠깐 손에 쥐어요. 상자보다는 약해요.
시크릿 스캔
Secret scanning
도면에서 열쇠 모양 찾기. 열쇠처럼 생긴 글자 뭉치를 자동으로 찾아 종을 울려요. → 도면 검사와 두드려 보기
API 키 / 토큰
API key / token
가게 입장권. 한 가게에만 통하는 열쇠. 그래도 열쇠니까 상자에 둬요. → 열쇠 대신 입장권
최소 권한
Least privilege
딱 그 문 열쇠만. 창고 열쇠로 금고까지 열리면 안 돼요. → 모자마다 열쇠 꾸러미
