BLP/Biba가 뭐예요?

접근통제 보안 모델 BLP와 Biba를, 등급 사다리를 오르내리는 걸 서로 반대로 막는 두 규칙 이야기로 풀어봤어요.

성의 방마다 비밀 등급이 매겨져 있어요.MAC(강제적 접근통제)에서는 이 등급을 아무도 마음대로 못 바꿔요.

아무 규칙 없이 오르내리면 둘 다 곤란해요.엿봐도 새고, 적어 내려도 새요. 비밀은 결국 아래로 흘러가요.

BLP와 Biba는 거꾸로 짝지은 두 규칙이에요.BLP(1973)는 기밀성을, Biba(1977)는 무결성을 지켜요. 둘 다 같은 등급 사다리 위의 규칙이에요.

BLP: 못 올려보기낮은 등급은 높은 비밀을 못 읽어요
BLP: 못 내려적기높은 등급이 낮은 장부에 못 적어요
Biba: 정반대못 내려읽기 + 못 올려적기
시험에 자주 나와요'BLP와 Biba의 차이'로 꼭 물어봐요

네 가지 규칙을 나란히 보면 이래요.BLP는 비밀이 아래로 새는 걸, Biba는 거짓이 위로 섞이는 걸 막아요.

엄격한 만큼, 실제론 다른 모델과 섞어 써요.MAC의 구체적인 규칙이 바로 이거예요. 회사 시스템은 보통 RBAC를 더 많이 써요.

한 줄로

BLP는 등급 사다리에서 못 올려보고(no read up) 못 내려적어서(no write down) 비밀이 새지 않게 하고, Biba는 정반대로 못 내려읽고 못 올려적어서 거짓이 섞이지 않게 해요.

Bell-LaPadula(BLP, 1973)는 기밀성을 지키는 MAC 모델로 No Read Up/No Write Down을 강제해요. Biba(1977)는 무결성을 지키는 모델로 No Read Down/No Write Up을 강제해, 신뢰도 낮은 주체가 높은 등급의 자료를 오염시키지 못하게 해요. 둘 다 등급(레이블) 기반 강제적 접근통제(MAC)의 구체적인 수학적 규칙이고, 군사·정부 기밀 시스템에서 비롯됐어요.
