What are Regression Assumptions?

Regression assumptions, told as a story about four conditions a weight-to-price scale must meet to hang straight and be trusted.

A scale was set up to predict price from weight.Can I trust this scale no matter what?

In some situations the scale swings off in strange ways.How much it wobbles changes by weight range — the scale needs certain conditions to hold.

Regression assumptions are four conditions that keep the scale hanging straight.Only when all four hold can the prediction and its confidence interval be trusted.

Linearitythe relation must be a straight line, not a curve
Independenceerrors must not entangle with each other
Equal Variancethe wobble size must stay the same across ranges
Normalityerrors should spread out in a bell-shaped curve

This is what it looks like when each condition breaks.A curved relation, entangled errors, a funnel shape, lopsided errors — each is a warning sign.

Break the assumptions and a number still comes out — but it can't be trusted.The error range and significance tests are only trustworthy when the assumptions hold.

In one breath

Regression assumptions are the four conditions — linearity, independence, equal variance (homoscedasticity), and normality — a prediction scale must meet to be trusted. Break them, and a number still comes out, but it can't be trusted.

Linear regression needs ① linearity (the relationship between predictors and outcome is linear), ② independence of errors (no autocorrelation), ③ homoscedasticity (constant error variance), and ④ normality of errors. If these break, the coefficient estimates still compute, but standard errors, confidence intervals, and p-values become distorted, leading to wrong conclusions. Check with residual plots, and if assumptions fail, consider variable transformations, robust standard errors, or a different model.

When grown-ups say it

Linearity
The assumption that the relation is straight, not curved. If it breaks, use a nonlinear model or transform the variables.
Homoscedasticity
The assumption that the wobble stays the same size across ranges. Breaking it shows up as a funnel-shaped residual plot.
Autocorrelation
Yesterday's error entangling with today's. A classic way independence breaks in time-series data. → see it in full
Residual
The gap between what the scale predicts and the real value. Its pattern reveals whether an assumption has broken.
Multicollinearity
Two variables effectively saying the same thing. A separate problem that muddies how coefficients are read.
Unbiased Estimator
A scale dial with no systematic tilt. The assumptions are what let the estimator's unbiasedness hold. → see it in full
Ensemble Methods
Several operators judging together. Sometimes used as an alternative when assumptions break. → see it in full
Cross Validation
Splitting into groups and testing in rotation. Separate from assumption checks, this verifies model performance. → see it in full
