What's the Difference Between Public and Private Blockchain?

Public vs private blockchain, told as a story comparing an open ledger anyone can read with a locked ledger only approved members use.

Isn't blockchain all just the same thing?Actually, who's allowed to join changes everything.

In one breath

A public blockchain is an open ledger anyone can join and verify; a private blockchain is one only approved members use. Consortium types sit in between.

A public blockchain is a permissionless, decentralized network — highly transparent but with slower consensus. A private blockchain is made up of only approved participants — faster, but more centralized. Consortium blockchains sit in between, run jointly by multiple approved organizations. Technical components and security considerations are covered in the blockchain tech & security page.

When grown-ups say it

Public Blockchain
An open ledger anyone can join. Its strength is decentralization and transparency.
Private Blockchain
A ledger only approved members use. Its strength is speed and control.
Consortium Blockchain
A middle ground run jointly by several organizations. Sits between public and private.
Blockchain Tech & Security
The inner workings — hashing, consensus, distributed storage. The technical skeleton both types share. → the Blockchain Tech & Security booth
Consensus Algorithm
The rule requiring agreement before writing to the ledger. The main reason public chains are slower.
Decentralization
Power spread across many, not held by one. Much higher in public than in private.
Smart Contract
A promise that runs itself once conditions are met. Used in both public and private chains.
