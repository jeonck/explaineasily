코드 생성이 뭐예요?

코드 생성과 코딩 에이전트를 코드 책을 산더미로 읽고, 도구 상자로 직접 돌려 보며 고치는 앵무새 이야기로 풀어봤어요.

목수가 물어요. 이 함수 왜 안 돼? 앵무새는 코드 책도 산더미로 읽었어요.코드도 글이에요. 앵무새가 읽은 책 더미에는 백과사전, 소설, 그리고 코드가 잔뜩 있어요.

코드는 규칙이 촘촘해서 잘 맞아요. 그런데 그럴듯한 코드도 이어 붙여요.예제가 산더미라 다음 콩이 잘 맞아요. 대신 없는 도구를 부르거나 없는 함수를 쓰는 그럴듯 앵무새가 코드에도 나와요.

코딩 앵무새는 코드를 읽고 쓰고, 도구로 직접 돌려 보며 고치는 앵무새예요.도구 상자에 파일 열기·실행·검색이 들어 있어요. 스스로 돌려 보고 고치는 앵무새를 코딩 에이전트라고 불러요.

작게 시켜요함수 하나씩
테스트를 먼저 줘요맞출 목표가 생겨요
실행 결과를 돌려줘요스스로 고쳐요
사람이 읽고 합쳐요마지막은 사람이

쪽지, 코드, 빨간 오류, 고침, 초록 통과. 오류를 돌려주면 몇 바퀴 돌아요.테스트를 먼저 주면 바퀴가 줄어요. 통과는 테스트가 시킨 것만 맞는다는 뜻이에요 — 그 이상은 아니에요.

통과했다고 안전한 건 아니에요. 그리고 이해 없이 붙인 코드는 나중에 아무도 못 고쳐요.보안 틈은 코드 검사로 따로 찾아요. 초록 ✓ 다음엔 사람 눈이 와요. 스스로 순서를 짜는 앵무새는 에이전트 이야기에서.

한 줄로

코드 생성 = 코드 책을 산더미로 읽은 앵무새가 다음 코드 콩을 잘 고르는 것. 코딩 에이전트는 도구 상자로 직접 돌려 보고 고치는 앵무새예요. 통과 ✓ 다음엔 사람이 읽어요.

Code generation / coding agent. 코드는 문법이 엄격하고 공개 예제가 방대해 LLM 의 다음 토큰 예측이 특히 잘 맞아요. 코딩 에이전트는 파일 읽기·쓰기·실행·검색 같은 도구 호출로 테스트를 돌리고 오류를 피드백 삼아 반복 수정해요. 존재하지 않는 API 호출(할루시네이션), 보안 취약점, 유지보수 불가 코드가 대표적 위험이라 코드 리뷰와 시큐어 코딩 검사가 필요해요.

어른들은 이렇게 불러요

코드 생성
Code generation

코딩 에이전트
Coding agent

코드 완성
Code completion
다음 줄 미리 말하기. 타자 치는 동안 다음 콩 몇 개를 미리 보여줘요.
테스트 주도
Test-driven
맞출 목표를 먼저. 테스트를 먼저 주면 앵무새가 그걸 통과시키려 고쳐요.
실행 피드백
Execution feedback
빨간 오류 돌려주기. 오류 메시지를 다시 보여주면 스스로 고쳐요. 몇 바퀴 돌아요.
코드 리뷰
