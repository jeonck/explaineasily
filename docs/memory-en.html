In one breath

Memory = the parrot's notebook kept outside the chat. The parrot has no memory and the tray is emptied when the chat ends, so what matters is written down and placed on the tray first next time. A wrong line stays wrong, and it is personal data.

An LLM is stateless: the context window vanishes when the session ends. Memory keeps conversation history, a user profile or summaries in a store outside the model and injects them into the next session's prompt. Short-term memory is the current context; long-term memory is external storage (summary, key-value or vector memory) — and because it is personal data, users need to view, correct and delete it.

When grown-ups say it

Memory (long / short-term)
Notebook / tray. Short-term is this chat's tray; long-term is the notebook outside the chat.
Conversation history
Everything said so far. Goes on the tray as is. When it grows, the earliest part falls off.
User profile
The guest section of the notebook. Name, likes, preferred tone and such.
Summary memory
A long chat in a few lines. The tray is small, so past chats are summarized into the notebook.
Vector memory
A notebook searched by tag. When the notebook is long, only relevant lines are pulled, shelf-style. → the shelf organized by tags
Session
One sitting of conversation. A fresh tray comes out when it starts and is emptied when it ends.
Personal data
The guest's story in the notebook. The guest must be able to view, correct and delete it. → privacy (security)
Context window
The tray. Where the notebook goes. It has a fixed size. → the tray in front of the parrot
