What is SCTP?

A story about one delivery contract with a dedicated lane per series, so one jam doesn't stop everything else.

Several series all get loaded onto one truck.They travel bundled together as one line.

If one stalls, everything stalls with it.Bundled as one line, one series' accident blocks the others too.

In one breath

SCTP is a transport protocol that puts several independent streams (lanes) inside one connection (association) and adds multi-homing for extra reliability.

SCTP (Stream Control Transmission Protocol) gives reliable, ordered delivery like TCP, but within one association it supports multiple streams, so a delay on one stream doesn't cause head-of-line blocking for the others. It also supports multi-homing — connecting over several IP addresses at once — so communication survives even if one path fails. It preserves message boundaries too, unlike TCP's raw byte stream.

When grown-ups say it

SCTP
A delivery contract split into lanes. A transport-layer protocol.
Association
The delivery contract as a whole. The SCTP equivalent of a TCP connection.
Stream
A dedicated lane per series. Several can exist inside one association.
Multi-homing
Keeping a backup road ready in advance. Keeps things running even if one path fails.
Head-of-Line Blocking
When one line jams and blocks everything behind it. What SCTP avoids by splitting into streams.
Difference from TCP
TCP is one line; SCTP is many lanes. Both still guarantee reliability.
Difference from UDP
UDP just sends without confirming. SCTP sends it reliably instead.
SIGTRAN
A telephony signaling use case where SCTP actually sees real use. One of SCTP's best-known real deployments.
