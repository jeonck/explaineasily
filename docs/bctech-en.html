In one breath

Blockchain is a ledger where each block holds the previous block's fingerprint (hash), so tampering with any one block breaks every link after it — making it a ledger where tampering shows.

Blockchain's core technical components are the hash chain, consensus algorithms (proof-of-work, proof-of-stake, etc.), distributed storage, and smart contracts. It resists tampering well, but 51% attacks, unrecoverable lost private keys, smart contract code bugs, and privacy exposure on public chains are security considerations that still need separate management. Public vs private is covered in the comparison page.

When grown-ups say it

Hash
Each block's own unique fingerprint. Change anything, and the fingerprint changes too.
Consensus Algorithm
The rule requiring agreement before writing to the ledger. The reason it's both slow and secure.
Smart Contract
A promise that runs itself once conditions are met. A code bug is hard to undo once it runs.
51% Attack
An attack that seizes the majority to shake the ledger. Riskier the fewer participants there are.
Private Key
The key nobody can recover for you if lost. Lose it, and the assets go with it.
Public/Private Blockchain
Two forms, split by who may join. These security points apply to both forms. → the Public vs Private booth
Distributed Ledger
The same ledger, copied identically in many places. The record survives even if one copy disappears.
Digital Twin
The twin you test things on first, on screen. A different exhibit in the same expo hall. → the Digital Twin booth
