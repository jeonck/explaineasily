What are Privacy-Enhancing Technologies (PET)?

Privacy-enhancing technologies, told as a story about a toolbox with several different ways to protect a guest.

Hide everything, and there's nothing left to analyze.Safe, but useless.

Show everything, and it's dangerous.The analysis works great — but it puts guests at risk.

PET is a toolbox holding several different tools, each protecting the guest its own way.There isn't just one way — you pick the tool that fits the situation.

Differential privacya little blur mixed into the result
Homomorphic encryptioncomputes while still locked
Federated learningthe data stays at each house
Synthetic dataa look-alike fake list

Each of the four fits a different situation.Some are fast and light; others are slow but very safe.

Perfect privacy and perfect accuracy can't both happen at once.Just like pseudonymization, how much to hide is always a trade-off.

In one breath

PET (privacy-enhancing technologies) = a set of tools — differential privacy, homomorphic encryption, federated learning, synthetic data — that protect data while keeping it usable.

PET is an umbrella term for technologies that let data be analyzed or used for training while still protected or encrypted. Differential privacy adds statistical noise to results so no single individual's presence can be detected; homomorphic encryption computes directly on ciphertext without ever decrypting it; federated learning gathers only trained models from each device, never the raw data itself; synthetic data generates fake records that mimic the real distribution. No single technique perfectly satisfies both privacy and accuracy or efficiency at once, so they are mixed and matched to fit the situation.

When grown-ups say it

Differential privacy
Mixing a little blur into the result. Adds statistical noise so no one can tell whether a single person changed the result.
Homomorphic encryption
Computing while still locked. Gets the answer without ever opening the lock. → the letter nobody can read without the key
Federated learning
Learning separately, at each house. The data never leaves home — only what was learned gets collected.
Synthetic data
A look-alike fake list. Fake guests with similar traits stand in for real ones, in analysis or testing.
Zero-knowledge proof
Proving something without showing it. Lets you prove you know a password without ever saying it.
Privacy-accuracy trade-off
A seesaw. Hide more, and it's safer but less accurate.
Pseudonymization
Swapping in a number tag. The basic tool used before reaching for PET. → swap in a number tag, lock the real name away
Data linkage/combination
Combining ledgers from several castles. Done safely only inside a special room. → the special reading room you can't carry data out of
