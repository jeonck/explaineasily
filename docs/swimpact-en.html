In one breath

A software project impact assessment = before commissioning a software project, a public agency weighs its effect on the private software market and checks whether existing commercial software could simply be bought.

A software project impact assessment is a system under Korea's Software Promotion Act: state bodies, local governments, and public institutions assess in advance how a software project would affect the private software market. Its aim is to support the commercial software industry by having agencies buy software that already exists, and it is done before the bid notice. A 2023 amendment lets the science ministry review the result and request improvements. It is a different activity from 'change impact analysis', which traces what a change to a system would touch, despite the similar name.

When grown-ups say it

SW Project Impact Assessment
The system for weighing a public software project's effect on the private market. Done before the project is commissioned.
Software Promotion Act
The law that requires this assessment. It also holds other rules for public software projects.
Ordering Agency
The public body commissioning the book. State bodies, local governments, and public institutions.
Commercial Software
The book already on the bookstore shelf. It can be bought instead of being built anew.
Crowding Out the Private Market
A publisher losing customers to free copies. The exact problem the assessment aims to prevent.
Re-assessment Request
Asking for the result to be looked at again. Results are published, so vendors can ask for it.
