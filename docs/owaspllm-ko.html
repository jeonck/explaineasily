OWASP LLM 보안 위협 Top 10이/가 뭐예요?

OWASP LLM Top 10을, 검사장마다 다른 이름으로 부르던 사고를 업계가 공용 번호판으로 정리한 게시판 이야기로 풀어봤어요.

검사장 입구에 낯선 게시판이 붙었어요.우리 검사장만의 기록이 아니라, 업계 전체가 모은 목록이래요.

검사장마다 같은 사고를 다른 이름으로 불러요.이름이 다 다르면 비교하거나 함께 배울 수가 없어요.

OWASP LLM Top 10은 업계가 합의한 공통 위험 목록판이에요.각 번호는 이름표일 뿐, 자세한 내용은 따로 찾아봐야 해요.

공용 번호로 부르기검사장이 달라도 같은 말
주기적으로 갱신하기새 사고가 쌓이면 목록도 바뀌어요
상세 페이지로 연결하기목록은 지도, 설명은 따로
점검용 안내일 뿐자동으로 막아주진 않아요

Top 10 각 항목은 더 자세한 이야기로 연결돼요.이 페이지는 목록 자체를 설명해요 — 각 항목의 속사정은 연결된 페이지에서 봐요.

게시판 자체가 막아주지 않아요.지도일 뿐이에요 — 길은 각자 페이지에서 걸어야 해요.

한 줄로

OWASP LLM Top 10 = 여러 검사장(현장)의 사고를 모아 업계가 합의한 공용 번호로 정리한 위험 목록판. 목록 자체는 지도일 뿐, 각 항목의 실제 대응은 그 번호가 가리키는 페이지에 있어요.

OWASP Top 10 for LLM Applications는 OWASP 재단이 커뮤니티 사례를 모아 매년 갱신하는 'LLM01~LLM10' 표준 위협 분류 목록이에요. 프롬프트 인젝션, 안전하지 않은 출력 처리, 학습데이터 오염, 서비스 거부, 공급망 취약점, 민감정보 유출, 위험한 플러그인/도구 설계, 과도한 자율행동, 과신뢰, 모델 도난이 대표 항목이에요. 이 목록의 가치는 '공용 언어'를 제공한다는 데 있고, 실제 방어 방법은 각 항목이 가리키는 세부 자료(가이드라인, 본 사이트의 개별 용어 페이지 등)에서 다뤄요.
