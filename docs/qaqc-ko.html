품질보증(QA)과 품질관리(QC)가 뭐예요?

편집 과정을 지키는 일과, 완성된 원고를 직접 읽고 표시하는 일은 서로 다른 일이에요.

독자가 오탈자를 발견했어요 — 이미 다 찍은 뒤에요.이미 독자 손에 들어간 뒤라 되돌리기 힘들어요.

나중에 찾으면 늦고, 고치는 값도 비싸져요.다 찍은 뒤 고치려면 전부 다시 찍어야 해요.

QA는 "만드는 방식"을, QC는 "만들어진 결과"를 봐요.둘 다 있어야 오탈자가 독자 손에 닿기 전에 걸러져요.

QA = 공정 점검교열 절차 자체를 봐요
QA = 예방 중심애초에 덜 틀리게 해요
QC = 결과물 검사완성된 원고를 직접 읽어요
QC = 결함 찾아 표시빨간 펜으로 콕 집어요

QA와 QC는 보는 범위와 시점이 달라요.QA는 넓고 미리, QC는 좁고 나중에 봐요.

둘 다 필요하지만 역할은 달라요.QC는 걸러내는 그물, QA는 애초에 덜 틀리게 하는 손질이에요.

한 줄로

QA(품질보증)는 편집 과정이 기준대로 지켜졌는지 보고, QC(품질관리)는 완성된 결과물을 직접 검사해 결함을 찾아내요.

QA(Quality Assurance)는 프로세스 표준·절차 준수를 점검해 결함 발생을 예방하는 활동이고, QC(Quality Control)는 산출물을 직접 검사·테스트해 결함을 찾아내는 활동이에요. QA는 '예방', QC는 '검출'에 가깝고, 둘은 서로 대체가 아니라 보완 관계예요.

어른들은 이렇게 불러요

Verification

Validation

Defect
