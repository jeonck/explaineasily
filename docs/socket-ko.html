소켓이 뭐예요?

소켓 통신을, 집주소와 호실번호로 만든 전용 우편함 구멍 이야기로 풀어봤어요.

한 집에 여러 사람이 살아요.집 주소만으론 몇 호에 사는 누구인지 구분이 안 돼요.

여러 프로그램이 동시에 통신하면 뒤섞여요.주소만으론 어느 대화가 어느 것인지 알 수 없어요.

소켓은 집주소와 호실번호로 만든 전용 구멍이에요.구멍 하나가 한 쌍의 연결을 통째로 책임져요.

IP 주소어느 집인지 알려줘요
포트 번호몇 호실인지 알려줘요
전용 구멍연결마다 따로 생겨요
열고 닫기통신 시작할 때 만들고 끝나면 치워요

소켓은 양쪽 끝에 하나씩 있어요.보내는 쪽 IP+포트, 받는 쪽 IP+포트가 한 쌍으로 연결을 이뤄요.

소켓은 구멍일 뿐, 봉투 선택은 따로예요.같은 구멍으로 등기봉투(TCP)도, 일반봉투(UDP)도 보낼 수 있어요.

한 줄로

소켓은 IP 주소(어느 집)와 포트 번호(몇 호실)로 만든, 한 쌍의 대화만을 책임지는 전용 우편함 구멍이에요.

소켓은 운영체제가 네트워크 통신을 위해 제공하는 종단점(endpoint)으로, IP 주소+포트 번호의 조합(소켓 주소)으로 식별돼요. 프로그램은 소켓을 열어(bind/connect) 데이터를 읽고 쓰며, TCP 소켓이면 연결 지향, UDP 소켓이면 비연결형으로 동작해요. 한 호스트 안의 여러 프로그램이 같은 IP를 쓰더라도 포트 번호가 다르면 서로 다른 소켓으로 구분돼요.
