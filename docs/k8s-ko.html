쿠버네티스(Kubernetes)가 뭐예요?

쿠버네티스를, 자동 좌석 배정 배지 중 가장 널리 쓰이는 실제 제품 이름 이야기로 풀어봤어요.

자동 배정 배지는 여러 회사가 각자 만들어요.모양도, 쓰는 법도 다 제각각이에요.

제각각이면 뭘 믿고 골라야 할지 몰라요.표준처럼 다들 쓰는 게 하나 있으면 좋겠어요.

쿠버네티스는 이 배지의 가장 유명한 실제 제품이에요.여러 건물이 같은 쿠버네티스를 표준처럼 써요.

파드 = 최소 묶음 단위칸막이 몇 개를 한데 묶어요
노드 = 바닥 한 칸(서버 한 대)파드가 올라서는 바닥이에요
디플로이먼트 = 몇 자리 유지할지 규칙숫자 하나만 정하면 돼요
서비스 = 어디든 찾아주는 안내 데스크자리가 바뀌어도 안내는 그대로예요

쿠버네티스에는 이런 전용 용어들이 있어요.파드·노드·디플로이먼트·서비스·네임스페이스, 다섯 가지예요.

쿠버네티스 자체가 복잡한 시스템이에요.사무실 1~2칸뿐인 작은 팀엔 오히려 과해요.

한 줄로

쿠버네티스 = 자동 배정 배지(오케스트레이션)라는 개념을 실제로 구현한 가장 유명한 제품 이름. 파드·노드·디플로이먼트 같은 전용 용어를 써요.

쿠버네티스는 컨테이너 오케스트레이션의 사실상 표준 플랫폼이에요. 컨테이너 묶음인 파드, 그 파드가 올라가는 서버인 노드, 원하는 파드 개수를 선언하는 디플로이먼트, 파드 위치가 바뀌어도 고정된 진입점을 제공하는 서비스, 자원을 논리적으로 나누는 네임스페이스로 구성돼요. '자동으로 재시작하고 자리를 배정한다'는 일반 개념 자체는 다른 플랫폼에도 있지만, 그 대표 브랜드가 쿠버네티스예요.

어른들은 이렇게 불러요

쿠버네티스
Kubernetes
가장 유명한 자동 배정 배지 제품. 컨테이너 오케스트레이션의 사실상 표준이에요.
파드(Pod)
Pod
칸막이 몇 개를 한데 묶은 최소 단위. 쿠버네티스가 다루는 가장 작은 단위예요.
노드(Node)
Node
파드가 올라서는 바닥 한 칸(서버 한 대). 여러 노드가 모여 하나의 건물(클러스터)을 이뤄요.
디플로이먼트(Deployment)
Deployment
몇 자리를 항상 유지할지 정하는 규칙. 숫자만 바꾸면 나머지는 쿠버네티스가 해요.
서비스(Service)
Service
자리가 바뀌어도 그대로인 안내 데스크. 파드 위치가 바뀌어도 찾아가는 길은 그대로예요.
네임스페이스(Namespace)
Namespace
층별로 나눈 구역 구분. 같은 건물 안에서 팀별로 자원을 나눠요.
오케스트레이션
Orchestration
자동 배정이라는 일반 개념 자체. 쿠버네티스는 그 개념의 대표 제품이에요. SRE 세계에서 개념 자체를 다뤄요. → 몇 대를 켤지 정하는 운영 본부
가상머신/컨테이너
VM / Container
독채 사무실과 칸막이 책상. 쿠버네티스가 자동으로 배치해주는 대상이 바로 이 칸막이(컨테이너)예요. → 독채 사무실과 칸막이 책상
