What is an Open API?

Open API, told as a story about a reading room opened with one standard request form, instead of everyone calling in separately to ask.

To see our data, outsiders have to call in and ask separately every time.Every requester asks differently, so it's explained from scratch each time.

In one breath

Open API = instead of everyone calling in separately, publishing a standard request form in advance so anyone can use the same way to borrow the data.

An Open API is both a policy and a technical approach: a public institution or company publishes its data or functionality externally through a standardized spec (request format, response format, authentication method), so that anyone following that spec can use it. It's documented with a spec standard like OpenAPI (Swagger), with usage keys and quotas managing how much gets used. Korea's public data portal 'Open API' is a well-known example.

When grown-ups say it

Open API
The reading room opened with one standard form. Anyone can request data the same way.
API Specification
The document that writes down the request form itself. Written using a standard like OpenAPI (Swagger).
API Key
The key that confirms who's borrowing. Issued automatically once you apply.
Public Data Portal
The government's biggest reading room of all. Open APIs from many agencies are gathered here.
Data Standardization
Making the response shape the same for everyone. Even with a form, a mismatched shape is hard to use.
API Gateway
The booth that actually handles the flood of requests. Open API is the policy; the gateway is the infrastructure that handles the requests → the front gate information booth.
External Interface File
The connection point for referencing another publisher's data. This kind of link gets counted too, when sizing up the work → the ruler that measures page count.
Usage Quota
The daily limit on how much one key can borrow. Ask too much, and that key is done for the day.
