강화학습이/가 뭐예요?

강화학습을, 미리 정답표 없이 행동마다 돌아오는 점수(보상)만으로 요령을 스스로 찾아가는 신입 조작원 이야기로 풀어봤어요.

신입 조작원에게 정답표가 없어요.훈련 교사가 미리 보여준 예제 없이 혼자 판단해야 해요.

일단 던져보고, 보너스와 벌점으로 배워요.맞으면 점수를 얻고, 틀리면 깎여요 — 그걸로 점점 요령을 익혀요.

강화학습은 정답표 없이 보상/벌점만으로 좋은 행동을 스스로 찾는 거예요.시간이 지날수록 점수를 더 많이 쌓는 쪽으로 행동이 바뀌어요.

시행착오일단 해보고 결과를 봐요
보상 신호맞으면 점수, 틀리면 벌점
탐험과 활용의 균형새로운 것도 가끔 시도해요
누적 보상 최대화한 번이 아니라 전체 점수를 봐요

지도학습과 강화학습은 배우는 방식이 달라요.둘 다 배우지만, 무엇을 보고 배우는지가 서로 달라요.

보상을 잘못 설계하면 엉뚱한 요령만 늘어요.강화학습은 어떤 보상을 주는가에 결과가 크게 좌우돼요.

한 줄로

강화학습 = 정답 예제 없이, 행동마다 돌아오는 보상/벌점만 보고 누적 점수를 최대화하는 쪽으로 스스로 행동을 바꿔가는 학습 방식.

강화학습(Reinforcement Learning)은 에이전트가 환경의 상태(state)를 보고 행동(action)을 선택하면, 환경이 보상(reward)과 다음 상태를 돌려주는 구조예요. 에이전트는 이 상호작용을 반복하며 누적 보상을 최대화하는 정책(policy)을 학습해요. 지도학습과 달리 정답 레이블이 없고, 탐험(exploration)과 활용(exploitation)의 균형, 보상 설계(reward shaping)가 핵심 난제예요. LLM 정렬에 쓰이는 RLHF도 이 틀 위에서, 사람의 선호를 보상으로 바꿔 모델을 강화학습시키는 방법이에요.
