CASB가 뭐예요?

클라우드 접근 보안 중개자(Cloud Access Security Broker)를 성 밖 창고로 가는 길의 문지기 이야기로 풀어봤어요.

요즘은 물건을 성 밖 창고에 둬요.사진은 사진 창고에, 편지는 편지 창고에. 성벽 밖이라 성 경비는 못 봐요.

아무도 모르는 창고가 생겨요."공짜 창고가 편해서요." 빨간 도장 종이가 어디 있는지 성은 몰라요.

CASB는 성과 창고 사이의 문지기예요.성에서 창고로 가는 길 한가운데 서서, 누가 어느 창고에 뭘 들고 가는지 봐요.

창고 목록어떤 창고를 쓰고 있나
허락된 창고아는 창고만 통과
가방 검사비밀 종이가 들었나
창고 안 규칙성의 규칙을 창고에도

낯선 창고는 막고, 아는 창고엔 규칙을 붙여요."비밀 종이는 창고에 못 둬요." "창고 문을 온 동네에 열어두지 마세요."

문지기 길을 안 지나면 못 봐요.집에서 바로 창고로 가면요? 그래서 창고 주인과 직접 약속(API)을 맺어 창고 안을 들여다보기도 해요.

한 줄로

CASB = 성과 바깥 창고 사이에 선 문지기. 누가 어느 창고에 뭘 들고 가는지 보고, 낯선 창고는 막고, 아는 창고엔 성의 규칙을 붙여요.

Cloud Access Security Broker. 가트너가 2012년에 붙인 이름이에요. 요즘은 SSE/SASE라는 묶음 안에 들어가 있어요. Netskope, Zscaler, Microsoft Defender for Cloud Apps 같은 것들.

어른들은 이렇게 불러요

클라우드 앱
SaaS / cloud app
바깥 창고. Google Drive, Slack, Dropbox처럼 성 밖에 있는 창고.
섀도 IT
Shadow IT
아무도 모르는 창고. 직원이 편해서 몰래 쓰는 공짜 창고.
허가 앱
Sanctioned app
허락된 창고 목록. 성이 알고 규칙을 붙인 창고. 나머지는 막거나 지켜봐요.
프록시 모드
Inline / proxy mode
길 한가운데 문지기. 모든 길이 문지기를 지나게 해요. 지나가는 순간 막을 수 있어요.
API 모드
API mode
창고 주인과의 약속. 길을 안 지나도 창고 안을 봐요. 대신 이미 들어간 뒤에 알아요.
클라우드 DLP
Cloud DLP
창고 가는 가방 검사. 빨간 도장 종이를 창고 길에서도 살펴요.
공유 설정 오류
Sharing misconfiguration
창고 문을 온 동네에 열어둠. "링크 있는 사람 누구나" 같은 것. 문지기가 제일 자주 잡는 실수.
SSE · SASE
SSE · SASE
문지기 묶음. 창고 문지기, 복도 파수꾼, 문마다 묻는 성을 한 묶음으로 파는 요즘 이름.
