재공학/역공학(3R)이 뭐예요?

재공학과 역공학(3R)을, 원본 원고가 사라진 오래된 절판본을 완성본만 보고 되짚어 다시 손보는 이야기로 풀어봤어요.

원본 원고는 사라지고, 인쇄된 책만 남아 있어요.그런데 이 책을 다시 손봐서 내고 싶어요.

그냥 새로 쓰자는 말, 그러면 더 비싸진다는 반박.사라진 원본을 무시하고 새로 짓는 건 더 비싸요.

역공학으로 개요를 되짚고, 재공학으로 다시 써 재출간해요.역공학 → 재구조화 → 재공학, 이 순서를 3R이라고 불러요.

완성본 뜯어보기있는 그대로 자세히 봐요
거꾸로 개요 추정하기있던 구조를 되짚어요
정리정돈하기되짚은 개요를 가지런히 해요
요즘 말로 다시 쓰기바뀐 독자에 맞게 고쳐요

3R은 이 순서로 진행돼요.사라진 원본을 되살리는 복원 작업에 가까워요.

새 책만큼 깔끔하진 않을 수 있어요.과거를 되살리는 일이지, 완벽하게 새로 짓는 일은 아니에요.

한 줄로

재공학/역공학(3R) = 사라진 원본을 완성본에서 거꾸로 되짚어 정리하고 다시 써 재출간하는 일.

3R은 역공학(Reverse Engineering, 산출물에서 설계를 되짚기)·재구조화(Restructuring, 기능은 그대로 두고 구조만 정리)·재공학(Reengineering, 현대 기술로 다시 구축)을 함께 부르는 말이에요. 원본 설계 문서나 소스가 부실한 레거시 시스템을 다루는 대표적 방법이고, 처음부터 새로 짓는 순공학(Forward Engineering)보다 기존 자산을 살리는 데 집중해요.

어른들은 이렇게 불러요

역공학
Reverse Engineering
완성본을 보고 개요를 거꾸로 추정하는 일. 설계 문서가 없을 때 특히 써요.
재구조화
Restructuring
내용은 그대로, 구조만 정리정돈하는 일. 역공학과 재공학 사이 단계예요.
재공학
Reengineering
요즘 말로 다시 써서 재출간하는 일. 3R의 마지막 단계예요.
순공학
Forward Engineering
원고부터 새로 써 내려가는 일. 3R과 반대 방향이에요.
레거시 시스템
Legacy System
오래돼서 원본 자료가 부실한 책. 3R이 다루는 대상이에요.
형상관리
Configuration Management
원고를 보관하는 서가. 원본이 잘 보관됐다면 3R 자체가 필요 없었을 거예요. → 원고를 지키는 보관 서가
기술 부채
Technical Debt
나중으로 미룬 정리를 쌓아두는 일. 오래 쌓이면 3R이 더 커져요.
GoF 디자인패턴
GoF Design Patterns
