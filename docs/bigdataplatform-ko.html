빅데이터 플랫폼이 뭐예요?

빅데이터 플랫폼과 처리 아키텍처를, 전국 독자 주문을 감당하는 출판사 창고 네트워크 이야기로 풀어봤어요.

전국 독자 주문이 하루에도 수백만 건씩 쏟아져요.창고 하나로는 다 담지도, 다 못 찾아요.

한 창고에 넣으려니 넘치고 느려져요.창고 하나, 일꾼 한 명으로는 속도가 안 나요.

빅데이터 플랫폼은 여러 창고에 나눠 담고 나눠서 정리해요.한 창고가 넘쳐도 다른 창고가 버텨줘요.

나눠 담기창고 하나에 다 넣지 않아요
나눠서 정리여럿이 동시에 정리해요
밤에 몰아서(배치)한꺼번에 정리해요
원본 그대로(데이터레이크)일단 그대로 쌓아둬요

'언제'와 '어떻게'를 목적에 맞게 따로 골라요.급하면 스트리밍, 양이 많으면 배치처럼 상황에 맞춰요.

창고를 늘린다고 저절로 빨라지진 않아요.정리 안 하고 쌓아두기만 하면 나중엔 아무것도 못 찾는 '늪'이 돼요.

한 줄로

빅데이터 플랫폼은 쏟아지는 자료를 여러 창고(분산 저장)에 나눠 담고, 여럿이 동시에(분산 처리) 정리하는 구조예요.

빅데이터 플랫폼은 대용량·고속·다양한 형태의 데이터를 분산 저장(HDFS 등)하고 분산 처리(Hadoop MapReduce, Spark 등)하는 구조예요. 정해진 시간마다 모아 처리하는 배치 처리와, 들어오는 즉시 처리하는 스트리밍 처리로 나뉘고, 원본을 그대로 보관하는 데이터레이크와 정제된 데이터를 구조화해 보관하는 데이터웨어하우스를 함께 두는 구성이 흔해요.

Distributed Processing

Stream Processing

Data Lake

Data Warehouse
