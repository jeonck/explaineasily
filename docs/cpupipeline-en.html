What is a CPU Pipeline?

CPU pipelining, told as a story about setting up several repair benches and overlapping several cars' repairs at once.

One mechanic handles a car from start to finish alone.The cars behind just wait the whole time.

Handling one car at a time slows down the whole queue.What if several benches worked at once?

A pipeline overlaps several cars across several benches at once.At any instant, four cars are each at a different stage.

Fetchbrings in the next instruction
Decodereads what the work is
Executeactually does the repair
Writebackwrites the result back

At the same moment, each car is at a different stage.This overlapping achieves a speed impossible one car at a time.

Sometimes a car still has to wait on the one ahead.Overlapping speeds things up, but one jam can stall the whole line.

In one breath

A CPU pipeline splits instruction processing into stages and runs them overlapped, like several benches at once, to raise overall throughput.

CPU pipelining splits processing a single instruction into stages — fetch, decode, execute, memory access, writeback — and overlaps them so different hardware handles each stage simultaneously. Because the next instruction can start before the previous one finishes, throughput rises significantly. However, data hazards (waiting on an earlier result) and control hazards (flushing the pipeline after a mispredicted branch) can cause stalls.

When grown-ups say it

Pipelining
Overlapping several cars across several benches. Significantly raises throughput.
Fetch
The stage that brings in the next instruction. The first stage of the pipeline.
Decode
The stage that reads what the instruction means. Unpacks the instruction into an executable form.
Execute
The stage that actually does the work. Where the computation actually happens.
Data Hazard
Needing to wait on the result of the car ahead. Happens because a result isn't ready yet.
Branch Prediction
Guessing ahead which path comes next. A wrong guess means flushing the pipeline.
Pipeline Stall
Cars behind stalling because a part hasn't arrived. Occurs when a hazard arises.
Throughput
How many cars get processed in a given time. The core goal of pipelining.
