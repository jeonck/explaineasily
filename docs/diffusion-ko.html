디퓨전 모델이 뭐예요?

이미지 생성 디퓨전 모델을 안개 가득한 종이에서 조금씩 안개를 걷어 그림을 꺼내는 화가 이야기로 풀어봤어요.

손님이 그림을 그려 달래요. 말하는 앵무새는 그림을 못 그려요.노을 지는 바다를 말로는 설명하는데, 종이는 그대로 비어 있어요.

왜냐면 그림은 콩을 한 줄로 잇는 게 아니라, 점 백만 개를 한꺼번에 정하는 일이거든요.앵무새는 다음 콩 하나를 고르는 새예요. 점을 하나씩 고르다간 밤을 새워요. 그래서 다른 화가가 필요해요.

디퓨전은 안개 가득한 종이에서 조금씩 안개를 걷어 그림을 꺼내는 화가예요.종이는 처음엔 안개(잡음)뿐이에요. 화가가 한 번 닦을 때마다 조금 또렷해지고, 쪽지가 어떤 그림을 꺼낼지 알려줘요.

쪽지는 구체적으로색, 분위기, 구도까지
여러 장 뽑아 골라요한 장에 걸지 말아요
걸음이 많으면 또렷대신 느려요
같은 씨앗, 같은 그림번호를 적어 둬요

안개, 흐릿, 조금 또렷, 또렷 — 걸음마다 안개가 걷혀요.걸음이 많으면 또렷하지만 느려요. 씨앗 번호가 같으면 같은 그림이 나오고, 여러 장 뽑아서 제일 나은 걸 골라요.

분위기와 색은 잘해요. 글자와 손가락 수는 자주 틀려요.화가는 본 그림들의 느낌을 배웠지 사실을 배운 게 아니에요. 남의 그림체를 통째로 배웠을 수도 있어서 저작권 얘기가 따라와요. 그림을 보는 앵무새는 따로 있어요.

한 줄로

디퓨전 = 안개 가득한 종이에서 조금씩 안개를 걷어 그림을 꺼내는 화가. 쪽지가 어떤 그림인지 알려주고, 걸음이 많을수록 또렷해요. 느낌은 잘 배웠지만 글자·손가락 수는 자주 틀려요.

Diffusion model. 순수 잡음에서 시작해 여러 스텝에 걸쳐 잡음을 제거하며 이미지를 만드는 생성 모델이에요. 프롬프트가 조건이 되고, 시드가 시작 잡음을 정해요. 학습 데이터의 분포를 배운 것이라 정확한 텍스트·해부학은 약하고, 학습 데이터 저작권 문제가 따라와요.

안개 한 번 닦기. 화가가 하는 일의 전부예요. 잡음을 조금 걷고, 또 걷고.

Steps

화가에게 주는 쪽지. 구체적일수록 원하는 그림이 나와요. → 조련 쪽지

Seed
씨앗 번호. 시작 안개 모양을 정해요. 같은 씨앗, 같은 쪽지면 같은 그림.

Generation vs understanding
그리는 화가 vs 보는 앵무새. 다른 일이에요. → 그림도 보는 앵무새

한 부분만 다시. 그림에서 고칠 곳만 안개로 덮고 다시 걷어요.
