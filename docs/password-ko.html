비밀번호가 뭐예요?

비밀번호(Password)를 성문 문지기에게 속삭이는 암호말 이야기로 풀어봤어요.

성문 문지기는 암호말을 물어요. 도둑은 암호말을 하나씩 맞춰 봐요.암호말이 '사과' 같은 짧은 말이면, 도둑은 몇 번 안 가서 맞혀요. 도둑은 지치지 않거든요.

짧으면 금방 맞히고, 똑같으면 하나 새도 다 열려요.게다가 도둑은 남들이 많이 쓰는 말 명부를 이미 갖고 있어요. '사과', '1234', '비밀번호'는 명부 맨 위에 있어요.

비밀번호는 문지기에게 속삭이는 암호말이에요.문지기와 나, 둘만 아는 말이에요. 길게, 문마다 다르게, 상자에 넣어두고, 아무한테도 안 불러줘요.

긴 문장으로외우긴 쉽고 맞히긴 어려워요
문마다 다르게하나 새도 하나만
잠긴 상자에외울 건 상자 열쇠 하나
아무한테도문지기도 되묻지 않아요

암호말은 잠긴 상자에 넣어두고, 상자 열쇠 하나만 외워요.문이 백 개여도 외울 건 하나예요. 새 문이 생기면 상자가 길고 이상한 새 암호말을 지어주고, 갈 때마다 꺼내서 속삭여 줘요.

새면 그 문 것만 바꿔요. 그리고 좋은 문지기는 암호말 말고 하나를 더 물어요.새어 나간 명부에 내 말이 있으면 그 문 암호말만 바꾸면 돼요 — 문마다 다르니까요. 문지기는 하나 더 확인하거나 아예 반지를 봐요.

한 줄로

비밀번호 = 문지기와 나, 둘만 아는 속삭이는 암호말. 길게, 문마다 다르게, 잠긴 상자에 넣고, 아무한테도 안 불러줘요.

Password. 나만 아는 문자열로 내가 나임을 증명해요. 길이가 짧거나, 여러 곳에 재사용하거나, 흔한 단어를 쓰면 무차별 대입과 크리덴셜 스터핑에 금방 뚫려요. 패스프레이즈, 비밀번호 관리자, MFA 가 그 약점을 메워요.

어른들은 이렇게 불러요

패스프레이즈
Passphrase
문장으로 된 긴 암호말. '보라색 고래가 빵을 구워요'. 외우긴 쉽고 맞히긴 훨씬 어려워요. 길이가 이상한 글자보다 힘이 세요.
비밀번호 관리자
Password manager
잠긴 열쇠 상자. 문마다 다른 긴 암호말을 지어주고 대신 기억해요. 나는 상자 열쇠(마스터 비밀번호) 하나만 외워요.
재사용
Password reuse
문마다 똑같은 암호말. 한 성에서 새면 다른 성 문도 다 열려요. 도둑이 제일 먼저 해 보는 일이에요.
크리덴셜 스터핑
Credential stuffing
새어 나간 명부로 문마다 찔러 보기. 다른 성에서 샌 이름과 암호말 명부를 들고 우리 성문에도 하나씩 넣어 봐요. 재사용만 안 해도 막혀요. → 열쇠 천 개를 다 꽂아보는 도둑
해싱
Hashing
문지기 일지엔 지문만. 문지기도 암호말을 그대로 적어두지 않아요. 지문만 적어두고, 내가 말하면 지문을 찍어 비교해요. → 물건마다 찍는 지문
MFA
MFA
암호말 말고 하나 더. 반지나 전화 숫자를 같이 물어요. 암호말이 새도 문은 안 열려요. → 세 번 확인하는 문지기
패스키
Passkey
암호말 없는 반지. 외울 것도, 속삭일 것도 없어요. 새어 나갈 말이 아예 없어요. → 성문을 알아보는 반지
유출 확인
Breach check
새어 나간 명부 들여다보기. 내 말이 명부에 올랐는지 알려주는 곳이 있어요 (Have I Been Pwned). 오르면 그 문 것만 바꿔요.
