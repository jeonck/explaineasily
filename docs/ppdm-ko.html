PPDM이 뭐예요?

프라이버시 보존형 데이터 마이닝(PPDM)을, 사람 한 명 한 명은 흐리게 하면서 마을 전체 흐름은 그대로 읽어내는 조사관 이야기로 풀어봤어요.

조사관이 마을 전체 경향을 알고 싶어요.장부엔 마을 사람 하나하나의 이름과 수입이 그대로 다 적혀 있어요.

이름만 지워도, 몇 가지 단서로 다시 찾아낼 수 있어요.이름만 지우는 것(마스킹)으로는 부족해요. 나이·동네·직업만 남아도 한 명으로 좁혀질 수 있어요.

PPDM은 개인은 흐리고, 흐름은 보이게 하는 여러 기법이에요.동형암호처럼 봉인한 채로 계산하는 방법도 PPDM의 한 가지 도구예요.

k명씩 묶기최소 k명은 똑같아 보이게 해요
살짝 흔들어 섞기차분 프라이버시, 값을 살짝 바꿔요
봉인한 채 계산동형암호 같은 방법도 써요
통계만 내보내기한 사람 한 사람의 줄은 안 나가요

기법마다 대가가 달라요.동형암호는 PPDM이 쓰는 도구 중 하나예요. 보호를 세게 할수록 통계의 쓸모는 줄어들어요.

보호와 쓸모는 늘 저울 위에 있어요.재식별 위험은 0이 되지 않아요. → 가명정보·개인정보 보호와 같은 고민을 데이터 분석에 적용한 거예요.

한 줄로

PPDM = 사람 한 명 한 명은 흐리게 하면서, 마을 전체의 흐름(통계)은 그대로 읽어내는 여러 기법의 묶음.

Privacy-Preserving Data Mining, 프라이버시 보존형 데이터 마이닝. 개인 식별이 가능한 원본 데이터를 그대로 분석하지 않고, k-익명성(동일 속성을 가진 개체를 k개 이상으로 묶음), 차분 프라이버시(결과에 수학적으로 제어된 노이즈를 추가), 동형암호(암호문 상태로 연산) 같은 기법으로 개인을 보호하면서 통계적 패턴은 추출하는 방법들을 통칭해요. 보호 강도와 분석 정확도는 трейд-off 관계예요.

어른들은 이렇게 불러요

PPDM
Privacy-Preserving Data Mining
개인은 흐리고 흐름은 보이게 하는 기법 묶음. 여러 기법을 아우르는 이름이에요.
k-익명성
k-anonymity
최소 k명이 똑같아 보이게 묶는 것. 한 명으로 좁혀지는 걸 막아요.
차분 프라이버시
Differential privacy
값에 수학적으로 노이즈를 더하는 것. 개별 값은 흐려지고, 전체 통계는 거의 그대로예요.
재식별
Re-identification
지운 이름을 도로 찾아내는 것. 남은 몇 가지 단서만으로도 가능해요. → 이름 대신 번호표
동형암호
Homomorphic encryption
봉인한 채로 셈하는 방법. PPDM이 쓰는 도구 중 하나예요. → 뜯지 않고 셈하는 봉인 편지
가명정보
Pseudonymized data
이름을 지운 기록. PPDM은 이 가명정보로 통계를 낼 때 특히 쓰여요. → 데이터 3법 개정
정확도 trade-off
Accuracy trade-off
보호를 세게 할수록 덜 정확해지는 것. 완벽한 보호와 완벽한 정확도를 동시에 가질 순 없어요.
