What is a Runbook?

A runbook, told as a story about the mechanic's notebook that spells out 'do this, then this' for every common failure.

In one breath

Runbook = a notebook spelling out the steps for each common failure, so whoever's on duty can fix it just by following along.

A document that spells out step-by-step responses to a recurring failure, also called a playbook. It can become the script for automation, helps onboard newcomers, and stays useful only if lessons from postmortems keep getting added.

When grown-ups say it

Runbook (playbook)
The notebook with steps for each failure. Also called a playbook.
Step-by-step procedure
The order written out as 1, 2, 3. Just follow it in order.
Relationship to automation
How the notebook eventually becomes an automation script. Repeating the same steps is a sign to automate them.
Rookie onboarding
How a newcomer learns from the notebook. They can follow along without extra explaining.
Keeping it current
Not leaving stale content as-is. Left unfixed, it becomes a 'stale runbook'.
Checklist
A list that makes sure nothing gets skipped. Often sits right inside the runbook.
Link to the postmortem
Adding what was learned from an incident into the notebook. → the record everyone writes without blame
Toil
The signal that shows up when the notebook keeps growing. The same repetitive chore, every day. → the chore that repeats every day
