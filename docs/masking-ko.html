데이터 마스킹이 뭐예요?

데이터 마스킹·토큰화·가명처리(Data Masking, Tokenization, Pseudonymization)를 손님 명부의 이름을 번호표로 바꿔 주는 이야기로 풀어봤어요.

목수가 새 선반을 연습하려고 명부 한 장을 달라고 해요.서기는 진짜 명부를 그대로 복사해 줘요. 이름, 방 번호, 열쇠 번호까지 전부요. 목수는 그냥 연습만 하려는 건데요.

연습 종이는 마을 작업장에 있어요. 진짜가 새요.연습용 종이는 성처럼 지키지 않아요. 도둑이 주우면 "철수는 방 3, 열쇠 12"를 알게 돼요. 연습이었는데 진짜 손님이 다쳐요.

데이터 마스킹은 이름 대신 번호표를 주는 거예요.이름은 번호표로 바꾸고, 열쇠 번호는 별로 가려요. 번호와 이름을 잇는 표는 잠긴 상자에 넣어요. 연습엔 진짜 이름이 필요 없어요.

이름 → 번호표되돌리려면 상자 열쇠가 필요해요
잠긴 상자진짜 표는 성 안에만
별로 가리기일부만 보여줘요
섞어 버리기되돌릴 수 없어요, 통계엔 충분

가리기, 번호표, 섞기 — 되돌릴 수 있는지가 달라요.별로 가리면 화면에 보여줄 때 좋아요. 번호표는 상자 열쇠로 되돌릴 수 있어요. 섞어 버리면 아무도 못 되돌려요 — 숫자만 셀 때 써요.

연습도 되고 숫자 세기도 되는데, 도둑은 못 써요.그래도 번호표 옆에 "방 3, 12월 3일 온 손님"까지 다 적혀 있으면 누군지 알아챌 수 있어요. 어떤 종이에 번호표를 붙일지는 색 도장이 정해요.

한 줄로

데이터 마스킹·토큰화 = 연습·통계용 종이에서 이름 대신 번호표를 주고, 일부는 별로 가리고, 번호↔이름 표는 잠긴 상자에 두는 일. 연습은 되고, 도둑은 못 써요.

Data Masking / Tokenization / Pseudonymization. 개인정보를 개발·테스트·분석 환경에 줄 때 실제 값을 토큰·부분 가림·비가역 변환으로 바꿔요. 토큰↔원본 매핑은 토큰 볼트에만 두고, 익명화는 되돌릴 수 없게 해요.

어른들은 이렇게 불러요

마스킹
Masking
별로 가리기. 철★★, 열쇠 ★★. 일부만 보여주고 되돌리지 않아요. 화면에 띄울 때 많이 써요.
토큰화
Tokenization
이름 → 번호표. 진짜 값 대신 아무 뜻 없는 번호를 줘요. 번호만 봐선 아무것도 몰라요.
가명처리
Pseudonymization
되돌릴 수 있는 번호표. 번호↔이름 표가 어딘가에 있어서, 열쇠가 있으면 되돌려요. 그래서 표를 꼭 지켜야 해요.
익명화
Anonymization
섞어 버리기. 표도 없고 열쇠도 없어요. 아무도 못 되돌려요. 숫자만 셀 때 써요.
토큰 볼트
Token vault
잠긴 상자. 번호↔이름 표를 두는 곳. 성 안에서 가장 잘 잠근 상자예요. → 금고 속 마스터 열쇠
개인정보
PII
손님 이름·방·열쇠. 누군지 알아볼 수 있는 모든 것. 이름만이 아니라 방 번호와 날짜를 합쳐도 그래요.
데이터 분류
Data classification
어떤 종이에 번호표를. 색 도장이 빨강이면 번호표부터. → 종이마다 찍는 색 도장
암호화와 차이
Versus encryption
봉인 편지는 열쇠로 다 읽혀요. 봉인 편지는 열쇠가 있으면 전부 읽혀요. 번호표는 아예 이름이 없어서 연습에 안전해요. → 열쇠 없이는 못 읽는 편지
