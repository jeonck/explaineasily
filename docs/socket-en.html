What is a Socket?

Socket communication, told as a story about a dedicated mailbox hole made from a house address and a room number.

Several people share one house.The house address alone can't tell apart who's inside.

Several programs talking at once get tangled.The address alone can't tell which conversation is which.

A socket is a dedicated hole made from an address and a room number.One hole handles exactly one pairing, start to finish.

IP addresssays which house it is

A dedicated holea fresh hole for each connection
Open and closemade when talk begins, removed when it ends

A socket sits at each end.The sender's IP+port and the receiver's IP+port together form the connection.

A socket is just the hole — the envelope choice is separate.The same hole can send a registered envelope (TCP) or a plain one (UDP).

In one breath

A socket is a dedicated mailbox hole made from an IP address (which house) and a port number (which room), responsible for exactly one pairing of talk.

A socket is the endpoint the operating system provides for network communication, identified by the combination of an IP address and a port number (the socket address). A program opens a socket (bind/connect) to read and write data — a TCP socket behaves connection-oriented, a UDP socket connectionless. Multiple programs on the same host sharing one IP are still told apart as long as their port numbers differ.

When grown-ups say it

Socket
A dedicated hole made from an address and a room number. Responsible for exactly one connection.
IP address
The house address. Points to which computer it is.
Port number
The room number inside the house. Points to which program it is.
TCP/UDP
The registered envelope and the plain one. Choosing which envelope to send through the socket hole. → the registered envelope and the plain one
bind/connect
The steps that open the hole and link it to the other side. The setup step before a socket can be used.
Port conflict
Trying to use a room number that's already taken. The same room number can't be reused at once.
Firewall
A wall with many doors. Sometimes blocks socket access by keeping only certain ports open. → the wall with many doors
IPv6
The far longer new house-address system. The house part of a socket address is moving to this system. → the new, nearly endless address system
