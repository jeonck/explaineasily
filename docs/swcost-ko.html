SW 사업 대가산정이 뭐예요?

SW 사업 대가산정을, 감이 아니라 잰 분량에 정해진 단가를 곱해 원고료를 매기는 이야기로 풀어봤어요.

작가마다 원고료를 다르게 불러요.원고료를 부르는 기준이 저마다 달라요.

감(느낌)으로 부르면 너무 싸거나 너무 비싸요.기준이 없으면 둘 다 억울해요.

대가산정은 규모 × 단가로 공정하게 값을 매기는 거예요.감이 아니라, 잰 규모에 정해진 단가를 곱해서 값을 매겨요.

규모부터 재기기능점수(FP) 자로 재요
단가표 적용정해진 기준표의 단가를 곱해요
난이도 보정어렵거나 급하면 값을 더 보정해요
투입 인월 환산사람이 몇 달 매달릴지도 가늠해요

이렇게 더해서 최종 대가가 나와요.규모값에 보정과 기술료, 실제 경비까지 더해야 비로소 값이 완성돼요.

기준표가 전부를 정해주진 않아요.공정한 기준표가 있어도 발주자-수행사 협상은 남아요. 다음 이야기: 값을 매긴 뒤 다른 책들에 끼칠 영향 보기.

한 줄로

SW 사업 대가산정 = 작가마다 다르게 부르던 원고료 대신, 규모(기능점수) × 단가에 보정계수와 기술료를 더해 공정하게 값을 매기는 일.

SW 사업 대가산정은 기능점수(FP) 같은 규모 지표에 공인된 단가(기능점수당 단가)를 곱하고, 난이도·규모·지역 보정계수와 기술료, 직접경비를 더해 소프트웨어 개발비를 산출하는 과정이에요. 한국에서는 '소프트웨어 사업 대가기준'(한국소프트웨어산업협회 고시)이 참고 기준으로 쓰여요.

어른들은 이렇게 불러요

SW 사업 대가산정
Software Cost Estimation
매수를 돈으로 바꾸는 계산. 규모 × 단가가 기본 뼈대예요.
기능점수단가
Rate per Function Point
자로 잰 분량 한 단위의 값. 규모는 → 매수를 재는 자로 먼저 재요.
투입공수(M/M, 인월)
Person-Month (M/M)
한 사람이 한 달 매달리는 일의 양. 일정과 인원을 가늠하는 단위예요.
난이도 보정계수
Difficulty Adjustment Factor
어려운 책이면 더 쳐주는 비율. 쉬운 산문과 복잡한 전문서는 같은 값일 수 없어요.
기술료
Technology Fee
출판사가 남기는 몫. 개발비 외에 이윤에 해당하는 부분이에요.
직접경비
Direct Expenses
종이값처럼 실제로 들어간 비용. 출장비, 장비 임차료 같은 실비예요.
소프트웨어사업 대가기준
Software Project Cost Standard
출판계가 다 같이 보는 단가표. 정부·공공기관 발주의 참고 기준이에요.
제값주기
Fair Pricing
너무 깎지도, 너무 부풀리지도 않는 것. 기준표의 가장 큰 목적이에요.
