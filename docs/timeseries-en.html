In one breath

AR/MA time-series analysis blends recent past values with weights to estimate what's next (AR), then corrects using how far recent forecasts missed (MA).

AR (AutoRegressive) models the current value as a linear combination of the past p values; MA (Moving Average) models it as a linear combination of past white-noise error terms. Together they form ARMA(p,q); differencing a non-stationary series to make it stationary gives ARIMA(p,d,q); adding seasonality gives SARIMA. The core assumption — that past patterns persist into the future — makes these models fragile against structural breaks like sudden events.

When grown-ups say it

AR (AutoRegressive)
A weighted sum of the last few days. More recent values get bigger weight.
MA (Moving Average)
A correction from recent forecast errors. Adds how far off you were into the next guess.
Stationarity
The assumption that the pattern doesn't shift over time. AR/MA only fits well when this holds.
Seasonality
A pattern that repeats, like holidays or harvest season. If present, add a seasonal term as in SARIMA.
Regression Assumptions
The conditions that keep the scale hanging straight. Time series is a cousin of regression and shares similar conditions. → what keeps the scale hanging straight
Unbiased Estimator
A scale dial with no systematic tilt. A property of the scale that produces the forecast itself. → the dial with no systematic tilt
Cross Validation
Splitting into groups and testing in rotation. Time-series forecasts are cross-validated over past windows too. → see it in full
Reinforcement Learning
A sorter that learns from rewards instead of an answer key. A different style of learning from forecasting. → see it in full
