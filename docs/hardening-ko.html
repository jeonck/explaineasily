하드닝이 뭐예요?

하드닝(Hardening)과 보안 기준선(Security Baseline, CIS 벤치마크)을 문이 다 열린 채로 온 새 방을 목록대로 문단속하는 이야기로 풀어봤어요.

새 방은 문이 다 열린 채로 와요.안 쓰는 창문이 열려 있고, 켜진 채로 온 도구들이 있고, 문에는 공장 암호말 쪽지가 붙어 있어요. 만든 사람은 "쓰기 편하게" 그렇게 보내요.

그대로 쓰면 도둑도 다 알아요.세상 모든 새 방이 똑같이 오니까, 도둑은 공장 암호말과 열린 창문 위치를 외우고 다녀요. 열쇠 천 개를 꽂아볼 필요도 없어요.

하드닝은 새 방을 쓰기 전에 목록대로 하는 문단속이에요.안 쓰는 문은 막고, 암호말은 바꾸고, 안 쓰는 도구는 끄고, 일지는 켜고, 판자는 최신으로. 남는 건 진짜 쓰는 문 하나뿐이에요.

안 쓰는 문은 막기문이 적을수록 지킬 게 적어요
암호말 바꾸기공장 암호말은 도둑도 알아요
안 쓰는 도구 끄기켜진 도구는 전부 들어올 틈
일지 켜고 판자 최신무슨 일이 있었는지 남게

현자들의 목록을 우리 성 목록으로 삼아요.방 종류마다 뭘 잠가야 하는지, 여러 성의 현자들이 이미 적어 뒀어요. 그걸 우리 성에 맞게 조금 고쳐서 모든 방에 똑같이 써요 — 이게 기준선이에요. 규칙 두루마리에 적어 두고요.

한 번 잠그고 끝이 아니에요. 계속 같은지 봐요.문단속 끝난 본보기 방을 똑같이 찍어내면 매번 처음부터 할 필요가 없어요. 그래도 누가 창문을 다시 열 수 있으니 달라진 방이 있으면 종이 울리게 해요. 바깥에서 세어 봐도 문이 줄어 있어야 해요 — 우리 성의 문 세기.

한 줄로

하드닝 = 문이 다 열린 채로 온 새 방을 쓰기 전에 목록대로 문단속 — 안 쓰는 문 막고, 암호말 바꾸고, 도구 끄고, 일지 켜고. 기준선 = 모든 방을 같은 목록으로, 그리고 계속 같은지 보기.

Hardening / Security Baseline. 서버·OS·앱·네트워크 장비의 기본 설정에서 불필요한 서비스·포트·계정을 없애고, 기본 암호를 바꾸고, 로깅과 패치를 켜서 공격 표면을 줄이는 작업이에요. CIS 벤치마크 같은 공개 기준을 조직에 맞게 조정한 것이 보안 기준선이고, 골든 이미지로 복제하고 설정 드리프트를 감시해요.

어른들은 이렇게 불러요

하드닝
Hardening
쓰기 전 문단속. 새 방에서 안 쓰는 문·도구·암호말을 치우는 일. 남는 건 진짜 쓰는 문 하나뿐이에요.
보안 기준선
Security baseline
모든 방을 같은 목록으로. 우리 성의 문단속 목록. 새 방은 전부 이 목록을 지나요. → 성의 규칙 두루마리
CIS 벤치마크
CIS Benchmarks
현자들의 목록. 여러 성이 같이 쓴 공개 목록. 방 종류마다 뭘 잠그고 왜 잠그는지, 어떻게 확인하는지 적혀 있어요.
공격 표면
Attack surface
도둑이 시도해 볼 수 있는 문의 수. 문단속은 이 수를 줄이는 일이에요. → 바깥에서 세는 우리 성의 문
기본 설정 위험
Insecure defaults
문 열린 채로 온 새 방. 편하라고 열어 둔 것들. 공장 암호말이 대표예요. → 문지기에게 속삭이는 암호말
불필요한 서비스
Unnecessary services
켜진 채로 온 도구. 안 쓰는데 켜져 있으면 그게 다 들어올 틈이에요. 끄거나 떼어 내요.
설정 드리프트
Configuration drift
다시 열린 창문. 문단속 끝난 방이 시간이 지나며 목록과 달라지는 것. 달라지면 종. → 빌린 창고 문단속 점검
골든 이미지
Golden image
본보기 방. 문단속 끝난 방을 똑같이 찍어내요. → 똑같이 찍어낸 짐칸
