IDS / IPS가 뭐예요?

침입 탐지·차단 시스템(Intrusion Detection / Prevention System)을 수배 전단을 든 파수꾼 이야기로 풀어봤어요.

복도 벽에 수배 전단이 붙어 있어요."이 얼굴, 이 가방, 이 말투 — 보이면 알려주세요." 망루 친구가 보내준 거예요.

전단이 있어도 보는 사람이 없으면 소용없어요.도둑이 전단 바로 앞을 지나가요.

IDS는 종을 울리고, IPS는 길을 막아요.둘 다 전단과 대조해요. IDS는 옆에 앉아 종만 울리고, IPS는 길 한가운데 서서 막아서요.

수배 전단아는 도둑의 얼굴
종IDS — 경비실에 알려요
막아서기IPS — 되돌려 보내요
옆 vs 가운데옆은 안 느려요, 가운데는 막을 수 있어요

전단과 딱 맞으면 종이 울리고 길이 막혀요.종은 경비실로 가요. 막힌 사람은 되돌아가요.

전단에 없는 얼굴은 못 잡고, 닮은 사람을 막기도 해요.새 도둑은 전단이 없어요 — 그건 버릇을 보는 복도 파수꾼(NDR) 몫. 그리고 IPS가 닮은 손님을 막으면 다들 화나니까, 확실한 전단만 써요.

한 줄로

IDS / IPS = 수배 전단(시그니처)을 들고 복도에서 지나가는 것을 대조하는 파수꾼. IDS는 종을, IPS는 막아서기를.

Intrusion Detection / Prevention System. Snort와 Suricata가 전단 쓰는 법이에요. 요즘은 대부분 성벽(방화벽) 안에 같이 들어 있어요(NGFW). 복도 파수꾼(NDR)은 버릇을, IDS는 전단을 봐요.

어른들은 이렇게 불러요

시그니처
Signature
수배 전단. 아는 공격의 생김새. → 남겨진 발자국과 같은 종류예요
규칙
Rule
전단 한 장. Snort, Suricata 규칙. 한 줄에 얼굴 하나.
IDS
Intrusion Detection System
옆에 앉아 종 울리기. 보고 알리기만. 길은 안 막아요.
IPS
Intrusion Prevention System
가운데 서서 막기. 같은 전단, 다른 자리. 막을 수 있는 대신 잘못 막을 수도.
인라인
Inline
길 한가운데. 모든 사람이 파수꾼을 지나야 해요. 파수꾼이 느리면 복도가 느려요.
탭 · 미러
TAP / out-of-band
옆에 앉기. 복사본만 봐요. 절대 안 느려져요. → 복도 끝 거울
오탐
False positive
닮은 손님 막기. 빨간 모자만 보고 막은 것. → 경비실의 고양이
NGFW
Next-gen firewall
전단 파수꾼이 든 성벽. 성벽(방화벽)에 IPS까지 넣은 것. 요즘 보통 이렇게 팔아요.
