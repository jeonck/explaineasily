In one breath

Homomorphic encryption = a cipher that lets you add or multiply a letter while it stays sealed. Whoever computes never sees the content, and the result comes out sealed too — only the owner can open it.

A cryptographic technique that lets you operate directly on ciphertext and get a result that, once decrypted, matches applying the same operation to the plaintext. Partial homomorphic encryption (PHE, e.g. Paillier) supports addition only; fully homomorphic encryption (FHE) supports both addition and multiplication. It lets a cloud compute on sensitive data without ever seeing it, though the computational cost is still very high.

When grown-ups say it

Homomorphic encryption
A letter you can do math on while sealed. You operate on the ciphertext itself. Decrypt the result, and it matches operating on the plaintext.
Partial HE
A simpler version that only adds. Supports only one operation — addition — directly on ciphertext.
Fully HE
A version that both adds and multiplies. Far more flexible, but far slower too.
Ciphertext computation
Doing the math while it's sealed. The one computing never needs to know the content.
Confidential computing
Hiding it even while it's being computed on. Homomorphic encryption is one cryptographic way to reach this goal.
Decryption
Opening the seal. Ordinary encryption has to be opened before you compute. → the letter no one reads without the key
Outsourced cloud computation
Handing the computing to a rented warehouse. Lets you hand it over without ever showing the content.
PPDM
Other techniques for mining statistics while protecting individuals. Homomorphic encryption is one tool PPDM uses. → PPDM
