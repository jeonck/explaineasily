In one breath

Software quality certification = an official mark from an outside body, applying the same standard to every book, not the publisher's own word.

Software quality certification is a designated test lab checking a product against fixed criteria such as ISO/IEC 25010, then awarding an official mark (e.g. GS Certification in Korea). A product-level mark like this differs from something like CMMI, which rates the maturity of the whole organization's process, not one product.

When grown-ups say it

Software Quality Certification
An official mark saying a fixed standard was met. The mark comes with an expiry date.
GS Certification
Korea's flagship software quality certification. A designated test lab runs the tests.
CMMI
A maturity rating for the whole publishing house's way of working, not one book. It certifies organizational maturity.
ISO/IEC 25010
The international standard the checklist's categories follow. Eight characteristics, including functionality, reliability, usability, and security.
QA
The proofreader's day-to-day internal quality work. Certification is an outside check, done only now and then.
IS Audit / PMO
Looks into how one book's process is going, from the inside out. Certification only checks whether the finished result meets the standard. → the last checker before publication
Usability Test
A test that digs deep into the checklist's one 'usability' item. → the test where a reader just tries the book cold
Methodology Tailoring
Applying editing rules differently from book to book. The certification standard is shared, but how each book gets made can still differ. → different editing rules for each book
