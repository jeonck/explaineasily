What is a Safety Evaluation?

An AI safety evaluation, told as a story about a tasting test before opening — scoring the kitchen against a fixed set of risky orders first.

Before the doors open, you don't know what it might serve.It might confidently serve a dangerous dish, too — and that needs to be known before any guest walks in.

Creative testing alone can't give you a number to compare.The inspector's surprise visit finds a new trick each time — so a different kind of test, one that measures the same way every time, is also needed.

A pre-launch tasting test scores the kitchen against a fixed set of risky orders, before it opens.The same risky orders go in every time, and the result comes back as a number.

In one breath

A safety evaluation is a tasting test that scores this kitchen with a number, against a fixed set of risky orders, before the doors ever open.

A safety evaluation scores an AI model against a standardized test set of risky behaviors before deployment, so results can be compared as numbers run after run. Unlike red teaming, where people creatively hunt for new weaknesses, an eval runs the same fixed test set on every version to answer, numerically, whether this version is safer than the last.
