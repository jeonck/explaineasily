What is Gradient Descent?

Gradient descent, told as a story about a hiking-club student on a foggy mountain, finding the lowest point by feeling only the slope underfoot. In one breath

Gradient descent = measuring the slope (gradient) at the current point, and moving a little in the opposite direction, repeatedly, to find the lowest point (minimum).

Gradient descent is an optimization algorithm that computes the gradient of a loss function (how wrong the model currently is), then updates parameters a little in the opposite direction by an amount set by the 'learning rate,' repeatedly reducing the loss. Too large a learning rate causes the process to oscillate or diverge around the minimum; too small makes convergence painfully slow. Because the gradient can near zero at more than one point, the process can get trapped in a 'local minimum' and miss the true 'global minimum.' In practice, stochastic gradient descent (SGD) — computing the gradient from only a portion of the data at a time — is widely used.

When grown-ups say it

Gradient Descent
Feeling the slope underfoot and stepping downhill, bit by bit. The most commonly used optimization method.
Gradient
Which way, and how steeply, the ground tilts underfoot. The downhill way is the opposite of this.
Learning Rate
The size of a single step. Too big overshoots; too small takes forever.
Loss Function
The height that represents how wrong things currently are. Lowering this height is the whole goal.
Local Minimum
A small dip — lowest nearby, but maybe not truly the lowest. Get stuck here, and the deeper valley goes unfound.
Global Minimum
The truly lowest point on the whole mountain. Gradient descent is never guaranteed to find it.
Stochastic Gradient Descent (SGD)
Gauging the slope from just a visible patch instead of the whole mountain. Much faster than surveying everything every time.
Convergence
Steps growing smaller and smaller until they settle at one spot. The signal that gradient descent is done.
