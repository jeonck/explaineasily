In one breath

Open-source license = the rule tag on shared supplies. Free to use, but you must credit the source and follow the tag's rule when you pass it on.

Open-source licenses are legal terms governing how source code may be used, modified, and redistributed. They range from lightweight 'permissive' licenses like MIT/BSD/Apache to 'copyleft' licenses like GPL, which require derivative works to be released under the same terms. Breaking a license can mean legal liability for copyright infringement.

When grown-ups say it

Open Source
Publishing source code so anyone can use and change it. But how free depends on which license.
Copyleft (e.g. GPL)
The tag that says: fix it, and you must open it too. Mix it in, and the whole thing may have to open up too.
Permissive License (MIT/BSD/Apache)
The tag that's free as long as you credit it. Safe to mix into closed, proprietary software.
License Compatibility
Whether two different tags can be mixed. Some combinations simply can't be mixed.
Attribution / Notice Obligation
Always writing down who made it. The minimum almost every tag asks for.
SBOM (Software Bill of Materials)
The parts list of which code went in. License tracking is part of it too. → the castle's parts list
Copyright
The original maker's right. Open source doesn't give up copyright — it's still there.
Dual Licensing
Putting both a free tag and a paid tag on the same thing. Use it free under one tag, or pay for different terms.
