What is Refactoring?

Refactoring, told as a story about a publishing house re-editing sentence structure while the plot stays exactly the same.

The older the manuscript, the scarier it gets to touch.The sentences are so tangled, nobody knows where to even start.

Changing the plot is risky, but leaving it as-is only makes things harder.Could we retouch just the sentences and leave the plot alone?

Refactoring re-edits the sentence structure while the plot stays exactly the same.The outside stays the same — only the inside gets reworked.

Merge duplicate sentencesthe same idea, said just once
Split long paragraphsshorter, easier to read
Unify names and termssettle on one consistent term
Small steps, checked each timechecking the plot hasn't moved

Refactoring repeats these four things.The proofreader checks the plot hasn't moved, every single time.

Without proofing (tests), you can't be sure.Refactoring isn't adding features — it's only reworking the structure.

In one breath

Refactoring is a re-edit that keeps the book's plot (external behavior) exactly the same while reworking only the sentence structure (internal design).

Refactoring improves a program's internal code structure without changing its external behavior (functionality, output). It's done in small steps — removing duplication, splitting functions/modules, unifying names — verified by tests at each step to confirm behavior hasn't changed. It is distinct from adding new features.

When grown-ups say it

Refactoring
Same plot, retouched sentences. The external behavior never changes.
External Behavior
The plot readers actually read. Must stay identical before and after.
Code Smell
The whiff of sentences gone tangled. A signal that refactoring is needed.
Unit Test
The proofing that checks the plot hasn't moved. The safety net that makes refactoring safe.
Technical Debt
A debt that must be repaid later. Refactoring is one way to repay this debt. → the debt you pile up to move fast now
Encapsulation
Tidying up what's inside the locked drawer. The box stays the same while only the drawer's inside gets refactored. → the writer's locked drawer
Design Pattern
The editing style guide. Often the destination refactoring moves toward.
Regression
An accident where the plot shifts while editing. The exact accident refactoring is built to avoid.
