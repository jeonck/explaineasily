What is IPv6?

IPv6, told as a story about stretching an address system that ran out into a far longer new one.

The addresses have all run out.The numbers in the old address system (IPv4) are all used up.

Several houses are forced to share one address.A new house can't get its own address, and sharing one is only a stopgap.

IPv6 stretches the address system far longer.Stretched from 4 groups to 8, creating addresses that are practically endless.

A much longer addressgrew from 32 bits to 128 bits
Practically endless countmore addresses than grains of sand on Earth
Self-assigning addressesa device can generate its own address

IPv4 and IPv6 differ on four things.IPv6 is far longer, far more plentiful, and doesn't need NAT.

The switch isn't complete yet.For now, both systems run side by side — a transition period (dual-stack).

In one breath

IPv6 stretches the address system from 32 bits to a far longer 128 bits, creating a practically endless supply of new addresses.

IPv6 (Internet Protocol version 6) is the next-generation protocol that stretches address length to 128 bits, solving the exhaustion of IPv4's roughly 4.3 billion addresses. It can give every device its own unique address without NAT, and includes features like stateless address autoconfiguration (SLAAC). Since it isn't directly compatible with IPv4, transition techniques like dual-stack and tunneling are used alongside it.

When grown-ups say it

IPv6
The far longer new address system. 128 bits, written as 8 groups.
IPv4
The address system used from the start. 32 bits — only about 4.3 billion addresses.
NAT
The stopgap of forcing several houses to share one address. Mostly unnecessary under IPv6.
Dual-stack
Running both an IPv4 and an IPv6 post office during the transition. Widely used right now.
SLAAC
A device generating and assigning itself an address. IPv6's own automatic-assignment method.
Dynamic routing protocol
The rule letting post offices redraw their map themselves. The map still has to keep redrawing itself under the new addresses. → the delivery map that redraws itself
Socket
A dedicated hole made from an address and a room number. The house part of a socket address is moving to this system. → the dedicated mailbox hole
DNS
The neighborhood address book. With addresses this long, the address book matters even more. → the neighborhood address book
