What is a Tool Sandbox?

A tool sandbox, told as a story about a drawer that opens one slot at a time for the apprentice — and locks again when done.

The apprentice grabs the knife, the flame, the phone — whatever it wants.With the whole drawer open, there's nothing to stop one tool's trouble from spreading.

If one tool misbehaves while everything else stays open too, the damage spreads.The apprentice decides its own next step — which is exactly why things need to be locked down ahead of time.

A tool sandbox isolates where a tool runs — so damage stays contained.Only one slot opens at a time, and even an accident stays inside that one slot.

Isolation contains a break; permission decides how much to grant in the first place.A sandbox in the security world is the general concept of isolation; this is the version built specifically for isolating a tool call. In one breath

Tool sandbox = letting the apprentice use a tool one drawer slot at a time, and locking it again afterward. If one slot breaks, the damage doesn't spread to the others.

A security mechanism that confines an LLM agent's function-call (tool) execution to an isolated environment — a process, container, or dedicated runtime. It restricts access to the filesystem, network, and system resources, so that even if one tool misbehaves or is abused, the damage stays inside that sandbox. It's the general sandboxing concept applied to the specific execution point of a tool call.
