국가 망 보안체계(N2SF)가 뭐예요?

국가 망 보안체계(N2SF)를 다리를 끊는 대신 검문소를 촘촘히 세우는 이야기로 풀어봤어요.

나라의 모든 성이 다리를 아예 끊었어요.다리 없는 섬처럼요 — 도둑도 못 오지만, 바깥 도구도 전혀 못 써요.

그런데 업무엔 점점 바깥 도구가 필요해요.다리를 다시 놓자니 도둑이 걱정이에요.

N2SF는 다리는 다시 놓되, 다리 위 검문소를 촘촘히 세우는 거예요.중요도별로 성 등급도 나눠서, 등급에 맞게 통제 수준을 다르게 해요.

등급별로 성을 나눠요중요도에 따라 통제 수준이 달라요
다리는 놓되 검문소 촘촘히구간마다 다시 확인해요
클라우드도 쓸 수 있게등급에 맞으면 허용해요
계속 지켜봐요한 번 통과가 끝이 아니에요

기존 방식과 N2SF는 다리를 다루는 법이 달라요.N2SF의 검문소 방식은 문마다 물어보는 성과 같은 생각이에요.

아직 초기 단계예요.모든 공공기관이 다 바꾸진 않았고, 등급 기준도 아직 다듬는 중이에요.

한 줄로

N2SF = 다리를 아예 끊는 대신, 등급별로 성을 나누고 다리 위에 검문소를 촘촘히 세우는 나라의 새 망 보안 틀.

N2SF(국가 사이버안보 기본틀, National Network Security Framework)는 국가정보원이 추진하는 공공부문 망 보안체계로, 기존의 물리적 망분리 중심 정책을 등급제와 제로 트러스트 기반의 논리적 망분리로 전환하는 것을 핵심으로 해요. 업무 중요도에 따라 보안 등급을 나누고, 등급에 맞는 통제를 적용해 공공기관도 클라우드 등 외부 서비스를 활용할 수 있게 하는 게 목표예요.

어른들은 이렇게 불러요

N2SF
N2SF
나라의 새 망 보안 틀. 국가정보원이 추진하는 공공부문 망 보안체계예요.
물리적 망분리
Physical network separation
다리를 아예 끊기. 기존 방식. → 다리 없는 섬 창고
논리적 망분리
Logical network separation
다리는 열되 검문소로. 물리적으로 끊지 않고, 접근을 통제해서 같은 효과를 내요.
등급제
Grading system
성마다 매긴 등급. 업무 중요도에 따라 1~3등급처럼 나누고, 등급별로 통제 수준이 달라요.
제로 트러스트 기반
Zero-trust based
문마다 다시 물어봐요. N2SF의 검문소 방식이 기대는 생각이에요. → 문마다 물어보는 성
공공 클라우드 이용
Public-sector cloud use
등급에 맞으면 허용. 물리적 망분리 아래선 거의 불가능했던 일이에요.
상시 모니터링
Continuous monitoring
계속 지켜보기. 검문소를 한 번 통과했다고 끝이 아니에요.
단계적 전환
Phased rollout
아직 다 바뀌진 않았어요. 기관마다, 등급 기준 자체도 계속 다듬는 중이에요.
