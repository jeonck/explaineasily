What is Process Synchronization?

Semaphores, mutexes, and monitors, told as a story about the rule for handing out the lift key.

Two mechanics reach for the same lift at the same time.Neither checks before reaching for it.

The crash happens in the gap between checking and using.This is called a race condition.

Synchronization = only the key-holder gets to use it.The next person waits until the key comes back.

Mutexexactly one key exists
SemaphoreN keys — up to N at once
Monitora room with a built-in waiting lounge
Critical Sectionthe stretch of work done while holding the key

Each tool differs in how many get in at once.A mutex is just a semaphore with N=1.

Not returning the key can itself cause a freeze."Only one at a time," taken too far, can lead to deadlock.

In one breath

Process synchronization = the rule that lets several tasks touch a shared resource like the lift only one at a time.

When several processes or threads touch the same resource (a variable, file, or memory region) at once, a race condition results. A mutex enforces mutual exclusion so only one enters the critical section at a time; a semaphore uses a counter to allow up to N; a monitor bundles a lock with condition variables at the language level to handle waiting and signaling safely.

When grown-ups say it

Race Condition
A crash in the gap between checking and using. Scramble the order, and the result changes each time.
Mutex
A lock with exactly one key. Only one task gets in at a time.
Semaphore
A lock with N keys. Up to N can be inside at once.
Monitor
A room with a built-in waiting lounge. Bundles a lock with condition variables.
Deadlock
Frozen forever, each waiting on the other's key. Not returning the key leads straight here. → the garage frozen waiting on each other's keys
Process/Thread
Several hands working the same car. Synchronization matters most for threads, which share "the same car." → one car, many hands
CPU Scheduling
The car order written on the job board. "Who goes first" is scheduling — this is "don't touch at once." → who gets the lift first
Cache Memory
A small toolbox holding only the frequently used tools. Similar coordination is needed when several cores share a cache line. → the toolbox that holds only the frequent tools
