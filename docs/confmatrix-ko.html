혼동행렬이 뭐예요?

혼동행렬을, 선별기의 판정과 실제 상태를 네 칸으로 나눠 적는 기록부 이야기로 풀어봤어요.

선별기가 정답률 99%라고 자랑해요.100개 중 상한 건 딱 1개 — 다 합격이라고만 찍어도 99%예요.

정답률 하나만 보면, 드문 실수는 숨어버려요.매번 놓쳐도 숫자는 좋아 보여요.

실제 상태와 판정을 네 칸으로 나눠 적는 기록부예요.숫자 하나가 아니라, 어떤 종류의 실수인지까지 보여줘요.

TP — 맞게 통과시킴진짜 합격을 합격으로 찍어요
TN — 맞게 걸러냄진짜 불합격을 불합격으로 찍어요
FP — 괜히 불합격(오탐)멀쩡한 걸 불합격으로 틀려요
FN — 놓침(가장 위험)상한 걸 합격으로 틀려요

네 칸의 숫자로 여러 성능지표를 계산해요.어떤 지표를 중시할지는, 어떤 실수가 더 위험한지에 달려 있어요.

FN과 FP 중 뭐가 더 위험한지는 상황에 따라 달라요.선별 기준(임계값)을 어디에 둘지는 이 둘의 비용을 저울질해 정해요.

한 줄로

혼동행렬 = 선별기의 실제 상태와 판정을 네 칸(TP·TN·FP·FN)으로 나눠 적는 기록부.

혼동행렬(Confusion Matrix)은 분류 모델의 예측을 실제 정답과 교차해 TP(참양성)·TN(참음성)·FP(거짓양성)·FN(거짓음성) 네 칸으로 정리한 표예요. 이 네 숫자로 정답률(Accuracy), 정밀도(Precision), 재현율(Recall), F1 점수 같은 성능지표를 계산해요. 클래스 비율이 한쪽으로 치우친 데이터(불균형 데이터)에서는 정답률만으론 모델 성능을 제대로 알 수 없고, 반드시 혼동행렬을 함께 봐야 해요.

어른들은 이렇게 불러요

혼동행렬
Confusion matrix
실제와 판정을 네 칸으로 나눈 기록부. 정답률 하나로는 숨겨지는 실수를 드러내요.
정답률
Accuracy
전체 중 맞춘 비율. 불균형 데이터에서는 믿을 수 없어요.
정밀도
Precision
합격 판정 중 진짜 합격 비율. 오탐(FP)을 줄이고 싶을 때 중요해요.
재현율
Recall
진짜 합격 중 놓치지 않은 비율. 미탐(FN)을 줄이고 싶을 때 중요해요.
불균형 데이터
Imbalanced data
100개 중 상한 게 1개뿐인 상황. 씨앗 단계의 치우침과 이어지는 문제예요. → 상한 씨앗으로 가르친 선별기
임계값
Threshold
합격·불합격을 가르는 기준선. 이 선을 어디에 긋느냐로 FP와 FN의 비율이 바뀌어요.
오탐·미탐
False alarm vs. miss
괜히 불합격(오탐) vs 상한 걸 놓침(미탐). 적대적 공격도 결국 이 네 칸의 숫자를 흔들어요. → 작물에 몰래 붙인 가짜 점무늬
ROC·AUC
ROC · AUC
임계값을 바꿔가며 그린 성능 곡선. 혼동행렬 하나가 아니라, 여러 임계값의 혼동행렬을 이어 붙인 그림이에요.
