What is a Workflow?

LLM workflows, told as a story about an order chart a person writes ahead of time, where the parrot does one thing per box.

Every day the parrot is told to translate, summarize, and make a table. The result wobbles.Monday the translation is missing; Tuesday the table is half done. Same request — why different?

Because when you ask for everything at once, the parrot picks the order itself. And that changes every time.With three jobs on one note, the parrot picks a new path every time. Some days it skips one.

A workflow is an order chart a person writes ahead of time. The parrot does one thing per box.Translate box, summarize box, table box. One note and one job per box. In an agent the parrot picks the order; in a workflow a person does.

Four boxes in a row, a check between each. If one is wrong, redo just that box.Run the same chart and it always takes the same path. An easy box needs only a small parrot — which parrot gets which box is its own story.

A chart is weak against surprises. There, put in one agent box.Fixed jobs get a chart; open jobs get an agent. When there are many boxes and several parrots, it becomes a parrot meeting.

In one breath

Workflow = an order chart a person writes ahead. The parrot does one thing per box, with a check between boxes. Fixed jobs get a chart; open jobs get an agent.

A fixed sequence of LLM calls (prompt chaining, pipelines) laid out by a person. Each step has one prompt and a validation step, and execution is deterministic, so it is easy to reproduce and debug. In an agent the model decides the order; in a workflow the code does. Routing small models to easy steps cuts cost.

When grown-ups say it

Workflow
The errand order chart. A person sets the order of steps ahead. The parrot does one thing per box.
Prompt chaining
Notes in a chain. The answer from one box goes into the next box's note.
Pipeline
The straight-line chart. A chart whose boxes run in one straight line. No forks.
Routing
Which parrot gets the box. Easy boxes go to a small parrot. → which parrot to ask
Difference from an agent
Who picks the order. A workflow: the person. An agent: the parrot. → the parrot that plans its own errands
Deterministic execution
Always the same path. Run the same chart and it takes the same path. When it fails, you know which box.
Validation step
The check between boxes. A person or a machine looks. If wrong, redo just that box.
Orchestration
Many boxes, several parrots. Deciding who does what, when. → the parrot meeting
