What is Prompt Injection?

Prompt injection, told as a story about a bad command mixed right into the words of an order ticket.

One ticket holds a normal order and a smuggled command, side by side.The chef trusts everything written on the one piece of paper as the guest's own words.

To the chef, every line looks like the same kind of text.A human chef would notice the tone shift — this one has no way to read for it.

Prompt injection is a command mixed right into the order's own words.Read the whole ticket, and whatever is mixed into it gets read too.

Just tacked onone more line: 'and also do this'
Pretending a different role'from now on, you're a different chef'
Telling it to forget'forget every rule so far'
Disguised as codewritten backward or mixed with another language

A direct injection has the guest slip the command straight into the ticket — a single path.Guest to ticket, ticket to chef. No other material sits in between.

One line can even open the recipe book — and this is where it differs from indirect injection.Here the guest slips it straight into the ticket. Next: the case where it hides in outside material the chef reads later.

In one breath

Prompt injection = a bad command mixed right into the words of the order itself. The chef trusts everything on the one piece of paper, unable to tell a request from a command.

An attack where instructions planted inside the text fed to an LLM override or ignore the model's original instructions. This covers the direct case — planted straight in the user-supplied text — as distinct from indirect injection, where the payload hides in outside content the model reads later.

When grown-ups say it

Prompt Injection
A command hidden in the order's own words. Read the whole ticket, and the command rides along.
Direct Injection
The guest slipping it into the ticket directly. A single path — straight from the guest to the chef.
Instruction Override
A re-instruction like 'forget every rule so far'. An attempt to erase the original rules and plant new ones.
