In one breath

A UNIX system is the garage's operator — it hands out bays and jobs in order, keeps files in a tree-shaped store, and locks every bin with three keys.

UNIX is an operating system supporting multiple users and multitasking: the kernel arbitrates resources (CPU, memory, files) and takes commands through a shell. Its file system is a tree rooted at /, and every file carries separate read (r), write (w), and execute (x) permissions for its owner, group, and others. Standardized commands give it strong portability across different machines.

When grown-ups say it

UNIX
An operating system that hands out bays and jobs in order. In use continuously since the 1970s.
Kernel
The garage's real, invisible manager. It allocates resources and arbitrates between jobs.
Shell
The command window where a mechanic gives instructions. Workers go through this window instead of touching the kernel directly.
File System (Tree Structure)
A storage layout that branches like a tree. Branches split off from a single root (/) at the top.
Permissions (rwx)
Three different keys for every bin. Owner, group, and others each get their own level.
Process
Each job that's currently running. Deciding which job runs first is another story in this world. → who gets the lift first
Multiuser / Multitasking
It takes on many people and many jobs at once. No single job monopolizes a bay.
Portability
The same commands still work after moving to a different garage's equipment. Thanks to a standardized set of commands.
