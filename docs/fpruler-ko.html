기능점수(FP)가 뭐예요?

기능점수를, 쪽수 대신 '무엇을 하는가'로 원고 분량을 재는 표준 자 이야기로 풀어봤어요.

쪽수만으로는 분량을 알 수 없어요.쪽수만으로는 일이 얼마나 되는지 알 수 없어요.

쪽수는 공정한 자가 아니에요.쪽수만 봐서는 일의 양을 공정하게 잴 수 없어요.

기능점수(FP)는 내용을 세는 표준 자예요.작가 솜씨나 글씨체와 상관없이, 같은 기준으로 규모를 재요.

입력 세기원고에 써넣는 칸이 몇 개인지
출력·조회 세기독자에게 보여주는 결과가 몇 개인지
저장소 세기책 안에서 관리하는 자료 묶음 수
외부 연계 세기다른 출판사와 주고받는 길 수

FP는 이렇게 계산해요.개수 × 가중치를 더해 UFP를 구하고, 보정계수를 곱해 최종 FP를 얻어요.

자로 재는 건 시작일 뿐이에요.작가 숙련도와 도구에 따라 실제 속도는 달라요. 다음 이야기: 잰 분량을 돈으로 바꾸는 대가산정.

한 줄로

기능점수(FP) = 쪽수가 아니라 입력·출력·조회·저장·연계 개수로 원고 분량을 재는 표준 자.

기능점수(FP)는 소프트웨어 기능을 외부입력(EI)·외부출력(EO)·외부조회(EQ)·내부논리파일(ILF)·외부연계파일(EIF) 다섯 가지로 나눠 세고, 복잡도 가중치를 곱해 미조정 기능점수(UFP)를 구한 뒤, 보정계수(VAF)를 곱해 최종 FP를 산출하는 규모산정 기법이에요. 코드 줄 수(LOC)와 달리 개발 언어나 작성자 스타일에 덜 영향을 받아요.

어른들은 이렇게 불러요

기능점수(FP)
Function Point
원고를 기능으로 세는 자. 쪽수 대신 '무엇을 하는가'로 규모를 재요.
UFP(미조정 기능점수)
Unadjusted FP
가중치만 곱해 더한 값. 아직 보정 전 원점수예요.
VAF(보정계수)
Value Adjustment Factor
난이도를 반영해 곱하는 수. 성능·보안 같은 요구조건을 반영해요.
EI(외부입력)
External Input
원고에 써넣는 칸. 자료를 안으로 들여오는 기능이에요.
EO(외부출력)
External Output
독자에게 보여주는 결과물. 계산하거나 가공해서 내보내요.
EQ(외부조회)
External Inquiry
그냥 찾아서 보여주는 것. 가공 없이 바로 보여주는 조회예요.
ILF(내부논리파일)
Internal Logical File
책 안에서 관리하는 자료 묶음. 이 출판사가 직접 유지보수해요.
EIF(외부연계파일)
External Interface File
다른 출판사가 관리하는 자료를 참고하는 것. 연결 자체는 → 개방형 API 쪽 이야기예요.
