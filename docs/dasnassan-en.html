What are DAS / NAS / SAN?

DAS, NAS, and SAN storage, told as the difference between my own desk drawer, the building's shared file room, and its dedicated storage network.

Each desk's own drawer runs out of room fast.Somewhere else to store things is needed.

Store separately in each office, and you get duplicates nobody can easily share.There needs to be a way to share it.

DAS=my drawer, NAS=shared file room, SAN=dedicated storage network.How they connect, and how widely they're shared, differ all three.

DAS plugs directly into my own deskmine alone to use
NAS shares over the hallway networkfile-by-file, across offices
SAN uses a dedicated network, block-levelfaster, but pricier
Wider sharing means more upkeepand cost climbs with it

Connection method and sharing scope split the three apart.Speed, cost, and sharing scope move together.

A dedicated storage network (SAN) is overkill for a small office.Picking the one that fits the scale matters.

In one breath

DAS is a drawer plugged directly into my own desk (just for me). NAS is the building's shared file room, reached over the hallway network (shared file-by-file). SAN is the building's dedicated storage network (block-level, fast, and pricey).

DAS (Direct Attached Storage) connects straight to one server. NAS (Network Attached Storage) connects over a regular network and shares files across multiple servers. SAN (Storage Area Network) uses a dedicated high-speed network for block-level access. Sharing scope, speed, and cost all increase in the order DAS < NAS < SAN.

When grown-ups say it

DAS (Direct Attached Storage)
A drawer plugged directly into my own desk. Mine alone to use.
NAS (Network Attached Storage)
The building's shared file room, over the hallway network. Shared file-by-file across offices.
SAN (Storage Area Network)
The building's dedicated high-speed storage network. Block-level — faster, but pricier.
Block storage
Storage carved into brick-like chunks. Covered in more depth on another page. → block, file, object
File storage
Storage organized like a folder tree. The style NAS uses.
Network bandwidth
How much the hallway network can carry at once. Directly affects NAS and SAN speed.
Cloud storage
The building itself storing things for you. Any of DAS, NAS, or SAN can sit underneath it.
Backup
Keeping one more copy of the file room elsewhere. The wider the sharing, the more backup matters.
