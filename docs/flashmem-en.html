What is Flash Memory?

Flash memory (NAND/NOR), told as a story about a parts warehouse that remembers its contents even when the garage's power goes off.

Parts must still be there even after closing.Some parts must not vanish when the power is off.

Parts on the workbench vanish once the shop closes.So a separate warehouse that survives power-off is needed.

Flash memory is a warehouse that remembers parts even off power.A warehouse that moves boxes in blocks — in two styles, NAND and NOR.

NAND — block accessmove whole boxes at a time
NOR — byte accessgrab a single drawer directly
NAND — cheap, roomyused in SSDs and USB drives

NAND yields whole boxes (blocks); NOR yields single drawers (bytes).Both describe the memory cell itself, not the FTL that manages it.

They serve different uses.Software inside an SSD separately manages this warehouse — the FTL.

In one breath

Flash memory is a warehouse that remembers its contents even off power — in two styles: NAND, which yields whole blocks, and NOR, which yields single bytes directly.

Flash memory is non-volatile semiconductor storage that keeps data without power. NAND allows only block-level read/write, making it cheap and high-capacity — used in SSDs, USB drives, and memory cards. NOR allows byte-level random access and execute-in-place (XIP), making it common for small firmware storage. The software layer that maps addresses and manages wear on NAND chips inside an SSD is the FTL.

When grown-ups say it

NAND Flash
A big warehouse that only yields whole boxes (blocks). Cheap and roomy — used in SSDs.
NOR Flash
A drawer cabinet that yields a single byte at a time. Costlier, but allows execute-in-place.
Non-Volatile Memory
Storage that keeps its contents when power is off. Flash is a prime example.
Block/Page
The warehouse's boxes and the slots inside them. NAND erases and writes in block-sized units.
Erase-before-Write
The box must be emptied before new parts go in. A well-known NAND constraint.
Execute-in-Place
Using a part straight out of the drawer. A NOR advantage — NAND can't do this.
SSD
A storage drive built from NAND warehouses. Inside, the FTL manages its blocks.
FTL (Flash Translation Layer)
The software that remaps which boxes are used inside the warehouse. Not the cell type itself, but the software managing it. → the shelf manager who never overwrites
