방화벽이 뭐예요?

방화벽(Firewall)을 문이 많은 성벽과 문 목록을 든 문지기 이야기로 풀어봤어요.

성벽엔 문이 여러 개 있어요.손님 문, 우편 문, 창고 문, 관리 문… 문마다 번호가 있어요. 그게 포트예요.

문이 다 열려 있으면 성벽이 없는 거나 마찬가지예요.도둑은 아무도 안 보는 뒷문(열린 포트)부터 찾아요.

방화벽은 문마다 목록을 들고 열고 닫는 문지기예요.'손님 문은 누구나, 우편 문은 우체국만, 나머진 닫힘.' 목록에 없으면 안 열려요.

문 번호포트
어디서 왔나주소
목록누가 어느 문으로
안 적힌 문은 닫힘기본은 벽돌

내가 내보낸 심부름꾼은 돌아올 때 열어줘요.'아까 나간 애 맞네' — 나간 기록을 기억해요. 처음 보는 사람은 안 열어요.

열린 문으로 오면 못 막고, 성 안은 안 봐요.손님 문으로 나쁜 쪽지를 들고 오면 문지기는 몰라요 — 창구 검토원 몫. 성 안 사람끼리는 안 봐요 — 문마다 묻는 성 몫.

한 줄로

방화벽 = 성벽 + 문마다 '누가 어느 문으로'를 적은 목록으로 열고 닫는 문지기. 안 적힌 문은 닫힘.

Firewall. 1990년대부터 있는 가장 오래된 파수꾼이에요. 요즘 성벽엔 수배 전단 파수꾼(IPS)과 봉인 뜯기까지 넣어 NGFW라고 불러요. iptables, pfSense, Palo Alto, Fortinet 같은 것들.

어른들은 이렇게 불러요

포트
Port
문 번호. 443은 손님 문, 25는 우편 문, 22는 관리 문.
IP 주소
IP address
어디서 왔나. 심부름꾼의 집 주소. → 남겨진 발자국
규칙
Rule
목록 한 줄. "우체국이 우편 문으로 → 허용" 같은 문장.
기본 거부
Default deny
안 적힌 문은 닫힘. 목록에 있는 것만 열어요. 반대로 하면 문이 다 열린 성이에요.
상태 추적
Stateful
나간 심부름꾼 기억하기. 답장은 들어오게, 처음 보는 건 못 들어오게.
패킷
Packet
심부름꾼. 쪽지 한 장 든 작은 사람. 문지기는 쪽지 겉봉만 봐요.
NGFW
Next-gen firewall
전단 파수꾼이 든 성벽. 수배 전단과 봉인 뜯기까지. 겉봉 너머를 조금 봐요.
내부 방화벽
Internal / segmentation firewall
복도 안의 성벽. 성 안 복도도 나눠요. → 복도를 지키는 사람
