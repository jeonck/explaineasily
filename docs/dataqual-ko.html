데이터 품질관리가 뭐예요?

데이터 품질관리를, 독자 주소록이 틀리거나 빠지거나 겹치지 않도록 계속 돌보는 이야기로 풀어봤어요.

주소가 틀려서 책이 엉뚱한 집으로 갔어요.같은 독자에게 두 번 보내기도 했어요.

주소록 정리는 나중에, 라고 미루다 생긴 일.데이터가 지저분하면, 아무리 잘 써도 독자에게 안 가요.

데이터 품질관리는 주소록을 정확·완전·유일하게 계속 관리하는 일이에요.한 번 정리로 끝나지 않아요, 계속 들여다봐야 해요.

실제와 맞는지 보기틀린 주소를 찾아요
빠진 항목 채우기빈 칸이 없게 해요
값 맞춰두기여기저기 다르게 적힌 걸 맞춰요
바로 갱신하기이사 가면 바로 고쳐요

데이터 품질은 이 네 기준으로 재요.교정자가 오탈자를 잡듯, 주소록도 똑같이 교정해요.

한 번의 청소로 끝나지 않아요.계속 돌보는 정원 가꾸기에 가까워요.

한 줄로

데이터 품질관리 = 독자 주소록이 정확·완전·일관·최신하도록 계속 돌보는 일.

데이터 품질관리는 정확성·완전성·일관성·유일성·적시성 같은 기준으로 데이터를 측정하고 정제하는 활동이에요. 데이터 프로파일링으로 현재 상태를 진단하고, 정제(cleansing)로 오류를 고치고, 이후엔 입력 단계에서부터 오류가 덜 생기도록 규칙을 정해둬요. 한 번의 정제로 끝나지 않고, 데이터 거버넌스 체계 안에서 계속 운영돼요.

어른들은 이렇게 불러요

데이터 품질관리
Data Quality Management
주소록을 계속 돌보는 일 전체. 정확·완전·일관·유일·적시 다섯 기준이에요.
데이터 프로파일링
Data Profiling
주소록 상태를 먼저 진단하는 일. 정제보다 먼저 해요.
데이터 정제
Data Cleansing
틀리거나 겹친 항목을 직접 고치는 일. 한 번 하고 끝나지 않아요.
데이터 거버넌스
Data Governance
주소록을 누가 어떻게 관리할지 정한 체계. 품질관리를 지속시키는 틀이에요.
데이터 표준화
Data Standardization
주소를 적는 형식을 하나로 맞추는 일. 일관성을 지키는 방법 중 하나예요.
마스터 데이터 관리
Master Data Management
독자 한 명당 기록을 하나로 통합하는 일. 중복 주소록을 막는 핵심이에요.
요구공학
Requirements Engineering
무엇을 정확히 적어야 하는지 미리 정하는 일. 주소록 항목도 결국 명세에서 정해져요. → 쓰기 전에 먼저 묻는 사람
정보시스템 감리/PMO
IS Audit/PMO
