다중접속·매체접근제어가 뭐예요?

CSMA/TDMA/CDMA를, 여러 집배원이 하나의 좁은 통로를 안 부딪히고 나눠 쓰는 규칙 이야기로 풀어봤어요.

여러 집배원이 같은 통로를 동시에 쓰려 해요.동시에 보내면 봉투끼리 부딪혀요.

규칙이 없으면 충돌이 나요.봉투가 섞여 둘 다 못 알아볼 글자가 돼요.

세 가지 규칙으로 안 부딪히고 나눠 써요.듣고 보내거나, 시간을 나누거나, 암호코드로 구분해요.

CSMA — 듣고 보내기비어 있으면 그때 보내요
TDMA — 시간 나누기각자 차례가 정해져 있어요
CDMA — 암호코드 구분동시에 보내도 코드로 구별돼요
충돌 후 재시도부딪히면 잠깐 쉬었다 다시 보내요

세 방식은 충돌을 다루는 법이 달라요.CSMA는 듣고 보내고, TDMA는 시간을 나누고, CDMA는 코드로 구분해요.

참여자가 늘면 각자 한계가 생겨요.CSMA는 충돌이 늘고, TDMA는 빈 시간이 아깝고, CDMA는 코드 조율이 복잡해져요.

한 줄로

다중접속 제어(MAC)는 여러 사용자가 하나의 통신 매체를 안 부딪히고 나눠 쓰도록 하는 규칙이에요(CSMA·TDMA·CDMA).

CSMA(Carrier Sense Multiple Access)는 전송 전 매체가 비어 있는지 감지하고, 충돌이 나면 감지·회피하는 방식(CSMA/CD, CSMA/CA)이에요. TDMA(Time Division)는 시간을 슬롯으로 쪼개 사용자마다 할당하고, CDMA(Code Division)는 사용자마다 고유한 확산 코드를 줘 같은 시간·주파수를 동시에 써도 구분되게 해요.
