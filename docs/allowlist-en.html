What is an Allowlist?

Allowlists and blocklists, told as a story about pinning a list of who may enter on the castle gate instead of wanted posters.

A wanted poster only stops thieves we already know.The guard only stops faces on the poster. A thief with no poster simply walks in.

A new thief is on no poster. Posters are always one step behind.Thieves wear a new hat every day. A list of what you know is always late against what you don't.

An allowlist is the list of who may enter. Everyone not on it is stopped.The guard never has to recognize a thief. He only checks the list — a thief seen for the first time, or one with no poster, is stopped all the same.

A tool list, a sender list, name tags on doors — lists are all over the castle.Which tools may run in the castle, which senders the gate accepts, the name tag on every door. It is the base of the castle that asks at every door.

In one breath

An allowlist = the list of who may enter; everyone else is stopped. Far safer than a blocklist that only stops known thieves — but keeping the list is work.

An allowlist (whitelist) names only what is permitted and denies everything else by default. A blocklist (blacklist) names only what to stop, so it is always late against new threats. Used for application allowlisting, IP allowlists and email senders — and because a stale list blocks normal work, it needs an owner and an update process.

When grown-ups say it

Allowlist (whitelist)
The list of who may enter. Only what is on the list passes. Everything else is stopped.
Blocklist (blacklist)
The wanted poster. Stops only known thieves; late against new ones. → the watchman with the wanted poster
Default deny
Not on the list, not coming in. The unknown is stopped first and added later. The opposite is default allow.
Application allowlisting
The tools-we-may-run list. Only the tools allowed to run in the castle. A strange box not on it never runs.
IP allowlist
The senders-we-accept list. The gate accepts letters only from listed villages. → the wall with many doors
Maintenance burden
The work of fixing the list. New carpenters, departed ones, changed tools — left alone the list locks out friends; fixed carelessly it lets thieves in.
NAC (network access control)
The name tag on every door. A list checked at every hole in the corridor. → a doorkeeper at every corridor hole
Zero Trust
The castle that asks at every door. A castle with an allowlist on every door. → the castle that asks at every door
