Minimum spanning trees, told as a story about piping every garage branch together using only the cheapest connections, with no loops.

In one breath

A minimum spanning tree (MST) connects every point using only the lowest-cost edges, with no cycles, so all points stay linked.

A minimum spanning tree is a subgraph of a weighted graph that connects every vertex, has no cycles, and minimizes the total edge weight. Kruskal's algorithm sorts all edges by weight and repeatedly adds the cheapest one that doesn't create a cycle (checked via union-find). Prim's algorithm starts from one vertex and repeatedly adds the cheapest edge connecting the growing tree to the outside, growing the tree one edge at a time. Both produce a tree with n-1 edges for n vertices.

When grown-ups say it

Minimum Spanning Tree
The network that connects everyone using the cheapest pipes. n vertices means n-1 edges.
Kruskal's Algorithm
The method of picking cheap pipes in order. Sorts all edges up front, then picks.
Prim's Algorithm
The method of growing outward from one branch. Extends only via the cheapest edge from what's connected.
Cycle
Pipes looping back to reconnect the same branches. Must never occur in an MST.
Weighted Graph
The map with a cost written on every pipe. An MST minimizes the sum of these costs.
Union-Find
The tool that quickly checks if two branches are already connected. Used by Kruskal to check for cycles.
Greedy Algorithm
The strategy of always picking the cheapest option right now. Both Kruskal and Prim follow this strategy.
Shortest Path Algorithm
Finding the single cheapest route between two specific points. A different problem — MST's goal is connecting everyone, not one pair.
