AMI(지능형 검침 인프라)가 뭐예요?

AMI를, 사람이 돌지 않아도 집집마다 계량기가 스스로 편지를 써서 우체국에 보내는 망 이야기로 풀어봤어요.

집배원이 집집마다 계량기 숫자를 손으로 적어와요.수천 집을 다 돌려면 한 달이 걸려요.

한 달에 한 번이라 중간 사정을 몰라요.중간에 새다가 멈췄는지 알 길이 없어요.

AMI = 계량기가 스스로 편지를 써서 자동으로 보내는 망이에요.사람이 돌지 않아도, 때마다 저절로 숫자가 도착해요.

자동 검침정해진 때마다 스스로
양방향 통신우체국도 지시를 보내요
이상 감지누수·정전을 바로 알려요
데이터 분석사용 패턴을 모아 봐요

자동 편지엔 네 가지가 담겨요.먼 집은 옆집 계량기를 거쳐 전달하기도 해요.

편하지만 지켜야 할 것도 있어요.자동 편지도 암호로 잠가둬요.

한 줄로

AMI = 사람이 돌지 않아도, 집집마다 계량기가 스스로 편지를 써서 자동으로 우체국에 보내는 검침망.

AMI(Advanced Metering Infrastructure, 지능형 검침 인프라)는 전기·수도·가스 계량기가 통신망을 통해 사용량을 자동으로 주기적으로 전송하고, 공급자도 계량기에 원격으로 지시를 내릴 수 있는 양방향 통신 체계예요. 과거 사람이 직접 방문해 읽던 방식과 달리, 실시간에 가깝게 이상 상황도 감지할 수 있어요.

어른들은 이렇게 불러요

스마트 미터
Smart Meter
스스로 편지를 쓰는 계량기. AMI의 핵심 장치예요.
양방향 통신
Two-Way Communication
우체국도 계량기에 지시를 보낼 수 있는 것. 원격 검침을 넘어선 제어까지 가능해요.
주기적 검침
Periodic Reading
정해진 때마다 저절로 숫자를 보내는 것. 한 달에 한 번이 아니라 훨씬 자주예요.
이상 감지
Anomaly Detection
누수·정전 같은 이상을 바로 알아채는 것. AMI의 실시간성이 만드는 장점이에요.
Modbus
Modbus
우체국장이 순서대로 묻는 단순한 쪽지 규칙. 현장 설비끼리는 이런 단순한 규칙으로도 통신해요. → 우체국장이 순서대로 묻는 쪽지 규칙
Ad-hoc 라우팅
Ad-hoc Routing
고정 우체국 없이 서로 길을 찾는 법. 먼 계량기가 이웃을 거쳐 전달할 때 쓰는 방식이에요. → 집배원끼리 길을 찾아 전달하는 법
5G·mMTC
5G mMTC
소형 소포 대량 전용 차선. 대량의 계량기를 한꺼번에 연결할 때 쓰여요. → 상황별 전용 차선을 가진 배송망
개인정보·보안
Privacy & Security
편지 내용을 엿보지 못하게 잠그는 것. 다른 세계(보안)에서 자세히 다루는 주제예요.
