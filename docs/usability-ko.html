사용성평가(Usability)가 뭐예요?

사용성평가를, 설명 없이 책을 건네고 독자가 어디서 헤매는지 조용히 지켜보는 이야기로 풀어봤어요.

오탈자 0건인데 독자는 헤매고 있어요.오탈자 없음과 쓰기 편함은 서로 다른 이야기예요.

편집팀은 당연히 쓰기 편할 거라 짐작만 해요.독자가 직접 넘겨보는 걸 본 적은 없어요.

사용성평가는 설명 없이 책을 줘보고, 어디서 헤매는지 지켜보는 시험이에요.독자를 평가하는 게 아니라, 책이 쓰기 편한지를 봐요.

학습 용이성처음 봐도 금방 쓰는 법을 알아요
효율성원하는 걸 빨리 찾아요
기억 용이성나중에 다시 봐도 안 헤매요
만족도읽고 나서 기분이 좋아요

독자 한 명 한 명을 조용히 지켜보며 기록해요.걸린 시간, 헤맨 지점, 도움 요청, 만족도를 적어요.

사용성평가는 오탈자를 잡는 일이 아니에요.옳고 그름이 아니라, 편한지 아닌지를 봐요.

한 줄로

사용성평가 = 독자에게 책을 그대로 줘보고, 설명 없이 어디서 헤매는지 조용히 지켜보는 시험.

사용성평가는 실제 사용자가 제품을 사용하는 모습을 관찰해 학습 용이성·효율성·기억 용이성·오류·만족도 등을 평가하는 방법이에요. 오탈자나 기능 오류를 잡는 품질보증(QA)과 달리, '맞는지'가 아니라 '쓰기 편한지'를 판단하는 사용자 중심 평가예요.

어른들은 이렇게 불러요

사용성평가
Usability Test
설명 없이 써보게 하고 지켜보는 시험. 책이 쓰기 편한지를 봐요.
학습 용이성(Learnability)
Learnability
처음 봐도 금방 쓰는 법을 아는 정도. 설명서 없이도 통하는 게 좋아요.
효율성(Efficiency)
Efficiency
원하는 걸 얼마나 빨리 찾는지. 걸린 시간으로 재요.
기억 용이성(Memorability)
Memorability
나중에 다시 써도 안 헤매는 정도. 오랜만에 봐도 금방 떠올라요.
만족도(Satisfaction)
Satisfaction
쓰고 난 뒤의 기분. 설문이나 인터뷰로 물어봐요.
오류율(Errors)
Errors
쓰다가 실수하는 횟수와 심각도. 다섯 번째 속성으로 자주 같이 봐요.
교정(QA)
QA / Proofing
오탈자와 기능 오류를 잡는 일. '맞는지'를 보는 거라, '편한지'를 보는 사용성평가와 역할이 달라요.
