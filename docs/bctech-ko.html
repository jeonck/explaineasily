블록체인 기술요소·보안이 뭐예요?

블록체인의 속 구조를, 블록마다 이전 블록의 지문을 물고 있는 장부 이야기로 풀어봤어요.

한 곳만 지키면 되니, 한 곳만 뚫리면 끝이에요.중앙 장부 한 곳만 고치면 아무도 몰라요.

블록마다 이전 블록의 지문을 물고 있어요.하나를 고치면 뒤의 지문이 전부 어긋나요.

블록체인은 블록마다 지문을 물고 있어, 몰래 고치면 들통나는 장부예요.몰래 고치는 게 사실상 불가능해요.

해시로 연결하기각 블록의 지문이에요
합의로 추가하기다수가 동의해야 해요
분산 저장하기여러 군데에 복사돼요
스마트 컨트랙트조건 맞으면 자동 실행

구조가 안전해도 조심할 점은 따로 있어요.열쇠 관리와 코드 품질은 사람 몫이에요.

그만큼 느리고 비용도 커요.한 번 적으면 지울 수 없다는 건 장점이자 단점이에요.

한 줄로

블록체인은 블록마다 이전 블록의 지문(해시)을 물고 있어, 하나라도 몰래 고치면 뒤가 전부 어긋나 들통나는 장부 구조예요.

블록체인의 핵심 기술요소는 해시 체인, 합의 알고리즘(작업증명·지분증명 등), 분산 저장, 스마트 컨트랙트예요. 변조에 강하지만 51% 공격, 개인키 분실 시 복구 불가, 스마트 컨트랙트 코드 버그, 공개형의 프라이버시 노출은 별도로 관리해야 할 보안 고려사항이에요. 퍼블릭·프라이빗 구분은 블록체인 비교 페이지에서 다뤄요.

어른들은 이렇게 불러요

해시
Hash
블록 하나하나의 고유한 지문. 하나라도 바뀌면 지문도 바뀌어요.
합의 알고리즘
Consensus Algorithm
다수가 동의해야 장부에 적는 규칙. 이게 느려지는 이유이자 안전한 이유예요.
스마트 컨트랙트
Smart Contract
조건이 맞으면 자동 실행되는 약속. 코드 버그는 되돌리기 어려워요.
51% 공격
51% Attack
다수를 장악해 장부를 흔드는 공격. 참여자가 적을수록 더 위험해요.
개인키
Private Key
잃어버리면 아무도 되찾아줄 수 없는 열쇠. 분실하면 자산도 함께 잃어요.
퍼블릭·프라이빗 블록체인
Public/Private Blockchain
누가 참여하느냐에 따른 두 형태. 이 보안 요소는 두 형태 모두에 적용돼요. → 퍼블릭·프라이빗 비교 부스
분산 원장
Distributed Ledger
여러 군데에 똑같이 복사된 장부. 한 곳이 사라져도 기록은 남아요.
디지털 트윈
Digital Twin
화면 속에서 먼저 실험해보는 쌍둥이. 같은 과학관의 다른 전시예요. → 디지털 트윈 부스
