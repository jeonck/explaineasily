헬스 체크가 뭐예요?

헬스 체크를 기구마다 '저 괜찮아요?' 하고 몇 초마다 물어보는 이야기로 풀어봤어요.

기구가 멈췄는데 안내판엔 '운행 중'이라고 떠 있어요.손님은 줄섰다가 허탕 쳐요.

멀리서 보면 멀쩡해 보여도, 속은 멈춰 있을 수 있어요.화면만 보고는 속을 알 수 없어요.

몇 초에 한 번씩 '딸깍, 저 괜찮아요?' 하고 물어보고, 대답 없으면 빼요.다시 괜찮아지면 명단에 자동으로 돌아와요.

주기적으로 물어봐요몇 초에 한 번씩요
대답 없으면 명단에서 빼요손님을 안 보내요
두 가지로 물어봐요살아있나, 준비됐나
괜찮아지면 자동 복귀사람이 안 건드려도 돼요

두 가지로 물어봐요 — 살아는 있어? 손님 받을 준비 됐어?살아있어도 아직 준비가 안 됐을 수 있어요.

확인 자체가 너무 잦으면, 그것도 부담이 돼요.적당한 간격이 필요해요.

한 줄로

헬스 체크 = 기구마다 몇 초에 한 번씩 '괜찮아요?' 하고 물어보고, 대답 없으면 명단에서 빼는 일. 괜찮아지면 자동으로 돌아와요.

일정 간격으로 서비스에 핑을 보내 살아있는지 확인하는 방법이에요. 살아있나(라이브니스)와 손님 받을 준비가 됐나(레디니스)는 서로 다른 질문이고, 결과는 로드 밸런서로 바로 전달돼 운행 명단을 갱신해요.

어른들은 이렇게 불러요

헬스 체크
Health check
몇 초마다 '괜찮아요?' 물어보는 일. 대답이 없으면 명단에서 빼요.
라이브니스
Liveness
살아는 있나? 묻는 질문. 이것만 통과해도 완전히 괜찮다는 뜻은 아니에요.
레디니스
Readiness
손님 받을 준비는 됐나? 묻는 질문. 살아있어도 아직 준비가 안 됐을 수 있어요.
핑/하트비트
Ping / Heartbeat
딸깍 하고 보내는 짧은 신호. 이 신호에 대한 대답으로 상태를 판단해요.
자동 제외·복귀
Automatic removal and return
대답 없으면 빠지고, 괜찮아지면 돌아오는 것. 사람이 일일이 안 건드려도 돼요.
로드 밸런서 연동
Load balancer integration
헬스 체크 결과를 바로 전해 받는 곳. 괜찮은 기구에만 손님을 보내요. → 여러 창구에 나눠 보내는 안내원
장애 조치
Failover
대답 없는 기구 대신 다른 걸 쓰는 것. 헬스 체크가 먼저 알아채야 장애 조치도 시작돼요.
서비스 디스커버리
Service discovery
지금 어떤 기구가 열려 있는지 알려주는 안내판. 헬스 체크 결과로 이 안내판이 늘 최신으로 유지돼요.
