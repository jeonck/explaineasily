# ELI5 — 쉽게 설명하기

## 목적

어려운 걸 **틀리지 않게** 쉽게 만든다. 쉬움을 위해 사실을 왜곡하면 실패다.
목표는 "읽고 나서 스스로 한 문장으로 다시 설명할 수 있는 상태".

## 절차

### 1. 청자를 정한다 (묻지 말고 추론)

- 개발자가 낯선 도메인을 물음 → 비유는 일상에서, 용어는 개발 용어 허용
- 비개발자가 기술을 물음 → 코드·약어 전면 금지
- 판단이 안 되면 **가장 낮은 수준**으로 쓰고, 끝에 "더 깊게 들어갈까요?"를 붙인다

### 2. 한 문장 핵심부터 (Bottom Line Up Front)

첫 줄은 반드시 결론. 배경 설명으로 시작하지 않는다.

> ❌ "이를 이해하려면 먼저 분산 시스템의 합의 알고리즘을…"
> ✅ "**여러 대의 서버가 '지금 누가 대장이냐'를 투표로 정하는 규칙입니다.**"

### 3. 비유를 하나만 고른다

- 비유는 **한 개**. 두 개 이상 섞으면 오히려 헷갈린다.
- 청자가 **직접 겪어봤을 일**에서 가져온다 (은행 창구, 택배, 식당 주문, 냉장고, 도서관).
- 비유를 쓴 직후 **비유가 깨지는 지점**을 한 줄로 밝힌다. 이게 정직한 설명과 거짓말의 차이다.

> "캐시는 자주 쓰는 물건을 책상 위에 꺼내두는 것과 같습니다. 다만 책상 위 물건은 원본이 바뀌어도 그대로라서, '언제 다시 가져올지'를 정하는 게 캐시의 진짜 어려운 부분입니다."

### 4. 층으로 쌓는다

```
1층: 한 문장 정의      (이게 뭔가)
2층: 비유 + 한계       (어떤 느낌인가)
3층: 왜 필요한가       (없으면 뭐가 불편한가)
4층: 구체적인 예 하나   (실제로 어떻게 생겼나)
5층: 더 알고 싶다면     (정확한 용어·다음 키워드)
```

짧은 질문이면 1~3층까지만. 길이는 이해도가 아니라 질문의 크기에 맞춘다.

### 5. 용어는 "번역 후 병기"

처음 쓰는 전문 용어는 쉬운 말로 먼저 쓰고 괄호에 원어를 넣는다.
이렇게 해야 나중에 검색할 수 있다.

> "요청을 잠깐 줄 세워두는 공간(큐, queue)"

## 문장 규칙

- 한 문장 = 한 개념. 접속사로 이어 붙이지 않는다.
- 수동태 대신 능동태: "처리된다" → "서버가 처리한다"
- 주어를 생략하지 않는다. **누가** 무엇을 하는지가 이해의 90%다.
- 숫자는 감각으로 바꾼다: "100ms" → "눈 깜빡할 사이(0.1초)"
- 영어 약어는 처음 한 번 풀어 쓴다: "API(다른 프로그램에 말 거는 창구)"

## 하지 말 것

| 금지 | 이유 |
|---|---|
| "간단히 말하면"으로 시작해놓고 어려운 말 이어가기 | 예고만 하고 안 지킴 |
| 비유 두 개 이상 겹치기 | 청자가 어느 쪽을 믿어야 할지 모름 |
| 정확성을 위해 조건절 덧붙이기 ("단, X인 경우를 제외하면…") | 1층에서는 버리고 5층으로 미룬다 |
| "쉽게 말해 그냥 ~입니다" 로 뭉개기 | 틀린 단순화. 깨지는 지점을 밝혀야 한다 |
| 다섯 살 흉내내는 말투 ("자, 친구들~") | 청자를 무시하는 인상. 말은 쉽게, 태도는 동등하게 |

마지막 항목이 가장 중요하다. **ELI5는 어휘를 낮추는 것이지 상대를 낮추는 게 아니다.**

## 코드·에러를 설명할 때

1. **무슨 일이 일어났는지**를 먼저 한국어 평문 한 줄로
2. 에러 메시지에서 **실제로 중요한 한 줄**만 인용 (스택 전체 금지)
3. **왜** 그렇게 됐는지 (원인)
4. **어디를** 고치면 되는지 (`파일:줄`)

> "`undefined is not a function` — 함수라고 부르려던 게 사실은 비어 있었다는 뜻입니다.
> `utils.js:42`에서 `format`을 가져오는데, 그 파일은 `format`이 아니라 `formatDate`라는 이름으로 내보내고 있습니다."

## 점검 체크리스트

설명을 쓴 뒤 스스로 확인한다. 하나라도 ❌면 다시 쓴다.

- [ ] 첫 문장만 읽어도 대략 무슨 얘긴지 아나?
- [ ] 설명 안에, 설명 없이 등장한 전문 용어가 있나?
- [ ] 비유가 딱 하나이고, 그 한계를 밝혔나?
- [ ] 쉬워지려고 **틀린 말**을 하진 않았나?
- [ ] 청자가 이걸 읽고 다음에 뭘 검색해야 할지 아나?
