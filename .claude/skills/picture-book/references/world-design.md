# 세계관 설계 — 새 분야를 시작할 때

분야 하나 = 세계 하나. 용어 100개가 같은 마을·같은 등장인물 안에서 풀려야 페이지끼리 이어지고, 독자가 한 번 배운 그림을 다음 페이지에서 다시 쓴다. 세계관은 `terms/<category>/_WORLD.md` 한 장으로 고정하고, 모든 작성자(사람·에이전트)가 먼저 읽는다.

## 좋은 세계의 조건

1. **다섯 살이 직접 겪어본 곳** — 집·마을·놀이터·부엌·학교·몸. 우주선·주식시장은 안 된다.
2. **역할이 물리적으로 구분되는 등장인물** — 모자 색·옷 색 하나로 "누구 편"인지 보인다.
3. **소품이 곧 개념** — 열쇠=권한, 편지=데이터, 종=경보, 장부=기록. 소품 하나가 용어 하나에 대응한다.
4. **긴장이 있다** — 지키는 사람 vs 노리는 사람, 만드는 사람 vs 망가뜨리는 것, 아픈 몸 vs 고치는 사람. 긴장이 없으면 패널 ①②(문제)가 안 써진다.
5. **깨지는 지점이 있다** — 모든 비유는 어딘가 틀린다. 그 지점을 패널 ⑤에서 정직하게 말할 수 있어야 한다.

## 세계관 카드 (`_WORLD.md` 형식)

```markdown
# <분야> 세계관: <한 줄>
## 무대
- <핵심 공간> = <실제 개념>   (예: 성 = 내 컴퓨터/조직, 마을 = 인터넷)
## 등장인물 (모자/옷 색 = 정체)
| 인물 | 그림 | 실제 |
|---|---|---|
| 도둑 | 빨간 모자 var(--bad) + MASK | 공격자 |
| 경비 | 초록 GUARD | 방어자/보안팀 |
| 파란 모자 | BLUE | 운영/경비실 친구 |
| 왕 | 노란 모자+보라 옷 | 경영진 |
## 소품 = 개념
| 소품 | 실제 | 처음 쓴 페이지 |
|---|---|---|
| 종 | 경보/탐지 규칙 | soc |
| 일지 | 로그 | log |
## 색·톤 규칙
- 낮 sky() = 평상시, 밤 night() = 공격 중, bad-soft 배경 = 문제 패널, good-soft = 해결
## 이미 쓴 비유 목록 (겹치지 않게)
| 용어 | 비유 제목 |
```

## 분야별 출발점 예시

| 분야 | 무대 | 긴장 | 소품 예 |
|---|---|---|---|
| 보안 (기존) | 성과 마을 | 도둑 vs 경비 | 열쇠·종·일지·편지·여분 상자·판자 |
| 소프트웨어 설계 | 집 짓기 (방·복도·문) | 살기 편한 집 vs 미로 | 도면·문·복도·수도관 |
| 네트워크/인프라 | 마을의 길과 우체국 | 편지가 제때 도착하나 | 우체통·배달부·길·다리 |
| 데이터/DB | 도서관 | 책을 못 찾음 vs 바로 찾음 | 책·서가·색인 카드·사서 |
| 머신러닝 | 요리 배우는 견습생 | 레시피대로 vs 감으로 | 레시피·재료·맛보기·손님 평가 |
| 금융/회계 | 마을 장터와 저금통 | 돈이 새나 vs 모이나 | 동전·장부·저금통·약속 종이 |
| 의학/생물 | 몸은 도시 | 병 vs 회복 | 도로(혈관)·경찰(면역)·발전소(심장) |
| 법/계약 | 규칙 두루마리와 재판관 | 약속을 지켰나 | 두루마리·도장·저울 |
| 프로젝트 관리 | 소풍 준비 | 출발 시간 vs 준비물 | 체크리스트·시계·짐 |

한 분야에 세계관 하나. 두 개를 섞지 않는다. 기존 분야의 세계에 억지로 끼워 넣지도 않는다 (보안의 "성"에 회계 용어를 넣지 말 것).

## 등장인물·소품을 늘릴 때

- 새 소품은 **처음 쓰는 페이지에서 정의**하고 `_WORLD.md` 표에 한 줄 추가한다. 다음 페이지부터는 설명 없이 쓴다.
- 자주 쓰이는 그림(3페이지 이상)은 `terms/_draw.py` 로 올린다 (예: dog, corridor, gate). 파일 안에만 두면 복붙이 늘어난다.
- 헬퍼 시그니처는 `(x, y, s=1.0, ...)` 로 통일. 원본 크기를 docstring 에 적는다 (좌표 계산에 필요).

## 비유가 틀리는 흔한 경우

| 증상 | 원인 | 처방 |
|---|---|---|
| 패널 ③에서 용어를 한 문장으로 못 씀 | 비유가 개념이 아니라 이름을 옮김 | 용어가 **하는 일**을 먼저 한 문장으로 쓰고 그 일을 하는 인물/소품을 찾기 |
| 두 페이지가 같은 비유 | 세계관 목록을 안 봄 | `_WORLD.md` 의 "이미 쓴 비유" 확인, 차이점을 패널 ①에서 명시 (예: 펜테스트 vs 레드팀) |
| 그림이 안 떠오름 | 비유가 추상적 | 소품을 손에 잡히는 물건으로 바꿈 (권한→열쇠, 정책→두루마리) |
| 다섯 살이 모르는 말이 본문에 | 원어가 샘 | glossary 로 내리고 본문은 그림책 말로 |
